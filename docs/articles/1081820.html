What I Found

Token Harbor

Website: https://tokenharbor.ai/
Documentation: https://tokenharbor.ai/docs
API: https://tokenharbor.ai/v1

Token Harbor has a full free tier for $0. There's no need to top up the balance for free models – the test account balance remained $0.00.

Currently, three models are available for free:

  • deepseek-v4.1-flash:free

  • deepseek-v4-flash:free

  • mimo-v2.5:free

The API is compatible with OpenAI. Free models need to be enabled in your personal account first.

I tested all three models via POST /v1/chat/completions with a zero balance:

deepseek-v4.1-flash:free — HTTP 200, ~2.1 s
deepseek-v4-flash:free   — HTTP 200, ~6.2 s
mimo-v2.5:free           — HTTP 200, ~51.3 s

Additionally, I repeated the requests with caching disabled. All three responded again with HTTP 200.

Request Limit

The official RPM is not specified. In the test, 20 requests per minute passed 20/20 without errors.

At 60 requests per minute, within the allotted 120 seconds, 31 out of 60 requests managed to complete. However, there were no HTTP 429 errors – instead of a hard block, requests start to take noticeably longer to process.

The free tier quota resets every 7 days. The countdown starts from the first request to a free model: in my test, the X-Th-Free-Resets header showed the next reset date exactly one week later.

The service does not specify the exact size of the free quota in tokens or money. Even after a series of tests, the API continued to show X-Th-Free-Used-Pct: 0, so its volume could not be determined with short requests.

There's another nuance: when enabling free models, the service warns that requests and their responses may be stored. A different data storage policy applies to paid models.

WoAiToken

Website: https://new.woaitoken.com/
Documentation: https://woaitoken.com/docs-category/newapi-zh/
API: https://new.woaitoken.com/v1

After registration, WoAiToken credited a $5 starter balance. There's also a daily login bonus: in my case, $0.0699 was added for the first day, so the balance increased to $5.07.

The API is compatible with OpenAI. When creating a key, you can select a separate model group. There are paid groups with different debiting coefficients, as well as a separate free group free with a 0x coefficient.

Three routes are available in the free group:

free-chat
free-code
free-fast

These are not fixed models but pools: the actual model is selected automatically and can change from request to request.

For free-chat, two requests resulted in HTTP 402, and for free-code, one request returned an unavailable model with HTTP 404, and another time a model that was already decommissioned with HTTP 410. free-fast was the most stable — 10 out of 10 requests were successful.

Most importantly, the free routes do not consume the main balance.

Unikey

Website: https://www.getunikey.ai/
Documentation: https://docs.getunikey.ai/
API: https://www.getunikey.ai/v1

After registration, Unikey credited 5,000 credits. The key is created immediately in the personal account, and the API is compatible with OpenAI.

Via GET /v1/models, the service returned a rather large list of models, including GPT, Claude, Gemini, DeepSeek, Kimi, MiniMax, and Qwen.

Among the most interesting, I tested the following:

gpt-6-astra       — HTTP 200, ~3.0 s

gemini-3.5-flash  — HTTP 200, ~1.8 s
deepseek-v4-pro   — HTTP 200, ~5.3 s
kimi-k3           — HTTP 200, ~4.5 s
MiniMax-M3        — HTTP 200, ~4.3 s
qwen3.7-max       — HTTP 200, ~23.2 s

gpt-6-astra returned HTTP 503 on the first try due to an upstream service limitation, but a repeated request was successful with HTTP 200.

Some models are present in /v1/models but did not have a working route at the time of testing:

gpt-5.6-sol   — HTTP 503
gpt-5.6-terra — HTTP 503
gpt-5.5       — HTTP 503

gpt-5.6-luna also had an HTTP 503, but the message indicated a temporary limitation of the upstream service, so the situation may change.

Among the tested models, gemini-3.5-flash responded the fastest – in about 1.8 seconds. The slowest was qwen3.7-max – around 23 seconds.

Limits

RPM: official limit not specified. In the test, the service withstood 60 requests per minute – 60/60 successful, without HTTP 429. In a separate run at 20 RPM, two requests received HTTP 524, so gateway errors are sometimes encountered.
RPD: official daily limit not specified.

How long will 5,000 credits last?

In my load test, 80 short requests to MiniMax-M3 consumed about 116 credits. If the consumption remains roughly the same, the initial 5,000 credits will last for about 3,000–3,500 short requests to this model.

On more expensive models and with long responses, consumption will be higher, so don't consider 5,000 credits as a large amount – it's more than enough for testing and occasional use.

Conclusion

If you specifically need an API that can be used without an initial top-up, out of everything tested, I liked Z.ai and Token Harbor the most. Both have actually working free models, not just a starter bonus for a few requests.

God Router also turned out to be an interesting option. It has several routes that work without top-up, including z-ai/glm-5.3-free with a clearly stated limit of 8 RPM.

WoAiToken is interesting for its combination of free routes and starter $5, but the free pools there are less predictable: the actual model can change from request to request, and sometimes upstream provider errors occur.

I would consider Unikey and ABCRelay more as an opportunity to try paid APIs for free. They provide a starter balance that lasts a long time with small requests, but it's still not permanent free access.
