We will have to spend much more time understanding what language models output. A few thoughts, tips, and tricks.

Text. This trick helps me a lot: ask your LLM to explain something in ASD-STE100. This is a controlled language specification, originally created for aircraft maintenance documentation. LLMs know this language well, and its strict constraints result in a clean style, and I often find such text much easier to read. Sometimes I tried to slightly soften the requirements, for example, I asked for "80% like ASD-STE100," because the specification is quite strict. But even better:

Diagrams and Images. Instead of text, ask the LLM to draw a diagram. It's often much easier to perceive, analyze, and understand. But even better:

Web Pages. Ask for the answer "in HTML" and get a beautiful interactive web page. LLMs are getting better at frontend and can create beautiful interfaces, animations, etc. But even better:

Explanatory Videos. Most of all, I believe in fully personalized explanatory videos created on any topic. Experiment with prompts like "Create a video explanation on topic X in the style of 3b1b. Use my ElevenLabs API key for voiceover" (the latter requires an API key, or ask the LLM to find decent free alternatives that work on your hardware). This is already starting to work!
