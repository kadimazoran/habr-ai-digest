As an AI enthusiast and technical writer who has been writing about AI for over five years, I'm already familiar with many terms. But then I thought, "There are AI terms that people should know, including newer ones."

So I wrote this article to cover 8 terms and explain them as simply as possible, without getting too technical. The next time you hear or read about them, you'll know what they mean.

1. Harness

A raw model is a brain in a jar. It can think. But on its own, it can't open Slack, send an email on your behalf, or even know when to stop.

A harness is the software wrapper around the model that lets it do all those things. It gives the model access to tools and information, manages permissions, and determines when the model should retry, stop, or ask for your help.

The easiest way to describe it is with a formula:

Agent = Model + Harness

For a code-writing agent, the harness provides tools: read files, edit code, run tests. It also manages the instructions and feedback the model receives.

Two applications can run on the same model but behave differently—simply because their harnesses give the model different tools, different instructions, and different ways to check its work.

This is why the software environment around a model is so important. OpenAI's article on harness engineering describes how the team built an environment where Codex could write code, run checks, and respond to feedback.

So when comparing AI tools, don't just look at which model is used, but also how the tool itself helps it accomplish your task.

2. Agents

An agent is a system that can perform a task in multiple steps, using tools.

For example, you could ask an agent to help with a return. With the right permissions, it could find the order, check the return policy, draft the request, and ask for your approval before submitting it.

The basic process looks like this: plan, act, check result, and decide next steps. Anthropic's writeup on agents explains how these systems use feedback to determine their next actions.

The diagram below shows an autonomous agent that uses tools in a loop, guided by feedback from its environment.

Think of an agent like an assistant who has a list of tasks and permission to use certain programs. You give it a goal, and it works through it step-by-step.

What it can accomplish depends on its tools and permissions. An agent that can only search the internet is not the same as an agent connected to your email, files, and calendar.

Before using an agent, check what it has access to, what it can change, and when it needs your approval.

3. MCP (Model Context Protocol)

MCP is essentially the USB-C for AI.

The protocol gives AI applications a single, standard way to connect to tools and data sources.

Without a common standard, developers have to build custom integrations for each AI application. MCP lets them build one connection that all compatible applications can use.

An MCP server exposes specific tools or data to an AI application. For example, it could let an assistant search company documents or create tasks in a project management system.

You can read about how these connections work in the MCP specification.

The USB-C analogy helps explain the idea of a common standard, but some setup is still required. The AI application needs to support the connection, and you need to grant permissions.

If a product's developers mention MCP support, check which services can be connected and what the assistant will be able to do through them.

4. Loop engineering

An agent often works in a loop: pick an action, perform it, check the result, and try again if necessary.

A code-writing agent might edit a file, run a test, read the error, and make another change.

This process becomes problematic when the agent repeats a failed action over and over, or stops before the task is complete.

Loop engineering is the design of how that loop works, including how the agent gets feedback and decides whether to continue. It's a new area of agent development, which you can read about in research on loop engineering.

You need to answer the following questions:

  • What counts as task completion?

  • How many times can the agent retry?

  • How much time or money can it spend?

  • When should it ask for help? Who or what checks the result?

For example, you might require a coding agent to pass certain tests before reporting a task as complete. You could also set it to stop after three failed attempts and explain what the problem is.

Harness provides the tools and controls. Loop engineering helps define how the agent uses them repeatedly to get the job done.

5. Skills

A skill is a stored sequence of actions that an agent can follow to perform a relevant task.

For an expense report, that sequence might explain which fields to include, how to group expenses, and what to do if a receipt is missing.

Instructions are stored in a SKILL.md file in the Agent Skills format. The package might also include scripts, templates, and reference documents. The format is described in Anthropic's writeup on skills.

You can add your own or template skills to Claude on the Skills tab.

In ChatGPT, you can add skills on the Settings page.

First, the agent sees the skill's name and description. When it finds a matching skill, it loads the detailed instructions. This means it doesn't have to read the entire procedure before performing each task.

MCP gives the operator access to tools and data. Skills explain how to use them to perform specific tasks.

For example, a connection might give the operator access to your spreadsheets. A skill could then tell it how to prepare your company's monthly sales report.

Instead of explaining the whole process in every chat, you write the instructions once and reuse them.

6. GEO/AEO

This isn't about creating agents. It's about being found by them.

In the past, people Googled and clicked on ten links in search results. That's SEO—Search Engine Optimization.

Now, they ask ChatGPT, Claude, Perplexity, or Google's AI Overview and just read the answer. There are fewer clicks.

  • GEO (Generative Engine Optimization): focuses on whether AI-generated answers mention your business, cite your content, or recommend your product.

  • AEO (Answer Engine Optimization): focuses on making content useful for direct answers, including featured snippets in search engines and AI assistants.

SEO = “get on the first page.”

GEO/AEO = “become a source that AI cites.”

These terms overlap, and companies don't always draw a clear line between them. Microsoft's guide to AEO and GEO covers both approaches.

For example, someone might ask an AI assistant, “What accounting tool is good for small businesses?” If you sell accounting software, you'd want your product mentioned in that answer.

Clear explanations, accurate product details, and reliable sources can help make your content useful. None of this guarantees that an AI assistant will mention it.

If you have a website or business, you might want to check if you're mentioned in AI answers, alongside your search rankings and traffic.

7. Computer Use

Computer Use lets AI interact with your screen: clicking, typing, scrolling, and selecting elements.

It works something like this:

Screenshot → decide what to do → click or type → re-check screen.


This way, an agent can fill out a form or complete a task through a website's interface.

Almost all popular AI chatbots, like ChatGPT, Claude, Perplexity, or Grok, already support Computer Use. In ChatGPT, you can enable this feature from the Integrations menu on the settings page.

8. AGI / Superintelligence

AGI, or artificial general intelligence, is AI that can perform a wide range of intellectual tasks at a human-comparable level.

This could include learning unfamiliar subjects, solving different types of problems, and applying knowledge across domains.

Researchers disagree on the exact definition and how to test for it. Google DeepMind's Levels of AGI framework offers one approach, based on how broad a system's capabilities are and how well it performs.

Superintelligence goes a step further. It refers to AI that significantly surpasses human intelligence across a wide range of intellectual tasks. A simple way to remember the difference:

  • AGI is AI with a broad range of capabilities, often described in terms of human-comparable performance.

  • Superintelligence is AI with a broad range of capabilities whose performance surpasses human intelligence.

Excelling at one task doesn't mean a system has either. A system might write high-quality code or solve complex math problems but struggle with other types of work.

When a company uses these terms, check what they mean by them and what results their system has demonstrated. This will give you much more information than just the name.

And in case you missed it: the US government has officially renamed AI to "superintelligence."
