How to connect an MCP server:

  1. Open the MCP server page on GitHub (links in this selection or in the table)

  2. Install the server using the specified command, usually via the terminal

  3. Add the MCP server to the settings of your Codex, Claude, Cursor, etc. (if you don't know how, ask a chatbot)

  4. If the server works with an external service, add the necessary API key or log in to your account

  5. Restart Codex or refresh the MCP server list

  6. Give the AI a task for which the server is intended. For example: “check the project for errors,” “write an article,” “query the database.”

Many MCP servers run directly on your PC. Often, the server itself is free and open-source, but some require API keys, accounts, or paid access to the service it works with.
