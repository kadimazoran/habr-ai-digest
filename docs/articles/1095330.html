I asked both neural networks 20 questions from the same niche (how to get into neural network responses, how much it costs, where to order). For each question, each neural network responded five times: three repetitions in a row within an hour, another after 5 days, and another after a month and a half. The report that you are in the response ages faster than it seems.

How I counted which neural network sources remained in the response

I consider a source to be a link that is referenced in the response text. For Alice AI, these are links marked as used in the response: usually there are three, although there is a list of 5-8 links below the response. For Perplexity (sonar-pro via API with search), these are links referenced in the text with a footnote number [n]. The median number of such links per response is 8 in the first measurements and 12 in the third.

I did not include the full Perplexity list in the main count. In the third measurement, the API started returning twice as many sources, and the longer the later list, the more random coincidences with the earlier one. For verification, I also counted using the full list: after a month and a half, less than half of the links still remain there.

I call the metric *previous links remaining*. This is the proportion of links from an early response to a question that are present again in a later response to the same question: |A∩B| / |A|. The denominator is only the early response, so it's not the Jaccard similarity of common links. The count is cumulative: links from all questions go into one denominator. For 5 and 45 days, each of the three hourly repetitions is compared with the later response, and all pairs go into the same denominator. I compare addresses exactly, after removing www, anchors, utm tags, and trailing slashes.

import re

def norm_url(u):
    u = u.split("#")[0].replace("://www.", "://")
    u = re.sub(r"[?&]utm_[^&]*", "", u)
    return u.rstrip("/")

def kept_share(early, late):
    """early, late: {вопрос: множество ссылок} -> |A∩B| / |A| по всем вопросам"""
    kept = total = 0
    for q, urls in early.items():
        if q not in late:
            continue
        a = {norm_url(u) for u in urls}
        b = {norm_url(u) for u in late[q]}
        kept += len(a & b)
        total += len(a)
    return kept / total if total else None

A background is also needed. In the first measurement, I compared each of the three hourly repetitions with the other two, resulting in six pairs. This is the variance without the passage of time: if some links were not repeated within an hour, it's due to the randomness of the response, not aging.

What proportion of links remains in the response to the same question after 5 and 45 days

After 5 days, slightly more than half of the previous links remain, and after 45 days, 27.5% to 35.5%. But not everything is repeated even within the same hour. For Alice AI, 78.3% of links remain within an hour, and for Perplexity, 73.9%: about a quarter changes without any passage of time.
