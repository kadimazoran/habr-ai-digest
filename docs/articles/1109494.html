The LeetCode platform has launched Project Problems, a new task format where developers are offered to create programs with the help of AI. Unlike the classic format, this one evaluates the ability to manage AI agents: set tasks for them, debug code, and bring development to a fully functional product.

The tasks simulate real-world problems faced by engineers in large IT companies. Among the first projects are a payment reconciliation system similar to Stripe, an event recommendation system like Bloomberg's, an inventory management API, and a product return processing mechanism like Amazon's. Tasks are performed in a "sandbox," with 60 minutes allocated for each. Users without a premium subscription get three attempts per day.

From November 16 to December 6, 2026, LeetCode will release 4 new tasks every Monday (12 in total). Users who successfully complete at least 8 of them will receive a reward in the form of in-game currency – LeetCoin.
