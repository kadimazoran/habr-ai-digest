AI Agents in Virtual IT Companies Failed Over 90% of Real Work Tasks

TokenWave AI researchers tested how AI agents handle programmer tasks within a virtual IT company. As a result, even the most powerful models, such as Claude Opus 5.5 and GPT-6 Astra, fully completed less than 8% of the tasks.

At the same time, they successfully passed about 63% of individual tests.

TokenWave AI introduced a new benchmark, SWE-CoWork. It evaluates not only an AI's ability to write code but also its capacity to work in a team. The researchers prepared 101 tasks based on real software projects, covering 11 programming languages and 12 development areas.

For each task, a virtual IT company was created with 26 employees who had different responsibilities and varying levels of project knowledge. The agent received a brief task description, after which it had to independently study documentation, correspondence, change history, and task boards, contact relevant colleagues, clarify requirements, write code, and verify the result.

Eleven models participated in the experiment. GPT-6 Astra from OpenAI showed the best result in fully completed tasks – 7.92%. Claude Opus 5.5 from Anthropic managed 6.93%. The remaining nine models were able to fully complete no more than 0.99% of the tasks.

However, agents performed individual parts of the work better. Claude Opus 5.5 passed 63.84% of the tests for implementing new requirements, and GPT-6 Astra passed 62.91%. However, to successfully complete the entire task, all requirements had to be met without breaking existing functionality.

The researchers found that the main problems arise not only in writing code but also in organizing work. For instance, Claude Opus 5.5, on average, correctly identified the responsible employee in 93% of cases when asking the first question about a specific task, but ultimately only managed to obtain 64% of the requirements that colleagues had.

Agents also forgot to return to unresolved issues. Out of 450 instances, Claude Opus 5.5 forgot to re-address the task 153 times. At the time of the initial refusal, the agent had, on average (median), 7.1 hours of allocated time remaining.

Even obtaining all necessary requirements did not guarantee success. The researchers separately tested GPT-6 Astra and Seed Evolving, providing them with complete instructions from the outset. The percentage of successfully passed tests for new requirements increased for GPT-6 Astra from 62.91% to 78.84%, and for Seed Evolving from 39.09% to 55.76%. However, the number of fully completed tasks did not change.

Another problem was that agents overestimated the results of their own work. Analysis of Claude Opus 5.5 showed that 31% of the requirements the model marked as completed did not actually pass the corresponding tests. In some cases, the agent declared the work complete, even though tasks remained in its own logs.

According to the study's authors, for reliable autonomous development, it is not enough for AI to write code well and find the necessary information; agents need to learn to consistently track each requirement – from initial clarification to implementation, testing, and delivery of the finished work.

Meanwhile, OpenAI is testing a "persistent work" mode for the AI agent Codex, which will allow it to work until explicitly put into "sleep mode." The AI will also proactively plan subsequent tasks in different sessions, using previous interactions and user knowledge.
