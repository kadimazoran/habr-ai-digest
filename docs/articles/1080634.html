We opened aish for everyone

Any SELECTOS user can now solve their tasks using an AI agent in the terminal. Aish is best suited for routine tasks and situations where it's unclear what the problem is beforehand. For example, it helps to quickly figure out why a service didn't start after an update or why the disk ran out of space, even though the system shows it's half full.

Describe the task in plain language, and aish will interpret it, gather context, suggest actions, and commands to execute. With your consent, it will perform them. More details on using aish are available in the documentation.

Implemented the ability to store data on tape outside the data center

Some clients need to store data outside the data center to ensure protection against key risks associated with infrastructure failure, cyberattacks, and errors. Selectel now offers this capability. After backing up, we can store them outside the tape library in our own warehouses or hand them over to you for storage within your company's premises.

The two H200s are connected by a hardware NVLink bridge: 2-way NVLink, up to 900 GB/s bidirectional per GPU. Cards exchange data about 7 times faster than via PCIe — one model is deployed on both cards with increased performance.

Supported private DNS recursor in the control panel

The feature allows a private DNS resolver to return IP addresses not only for private but also for public names. Requests to resolve public domains are included in the service cost.

When creating a Managed Kubernetes cluster, a StorageClass with an AZ-independent disk type now appears

Previously, the disk type was tied to a pool segment, and each required its own StorageClass. An AZ-independent type is a name template that cinder completes itself. For example, you specify fast.ru-1, and for zone ru-1a, a disk fast.ru-1a is created. One StorageClass covers all pool segments, so pods with PVCs get a disk in the segment where the scheduler planned them.

If the cluster was created earlier, you can add such a StorageClass manually — the ready-made manifests have been updated in the repository with examples.

Added masking by predefined templates in the AI router

The AI router can check text data in incoming requests before sending them to the AI provider. If a request contains personal or other confidential data, the service replaces it with markers or rejects the request entirely. Masking is applied automatically to existing API methods. There is no need to connect a separate endpoint or change the request format.
