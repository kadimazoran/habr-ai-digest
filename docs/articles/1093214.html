In this tutorial, I will explain how to use ComfyUI as an API and quickly create a web application accessible from the internet. In the application, I will be able to quickly configure the interface for changing tasks without programming.

Preparing the API Workflow

For this example, I used the "Flux.2 [Klein] 4B: Text to Image" workflow template.

I will test its functionality and then export it for the API. I open the JSON file and copy its content to the clipboard.

Local API Testing in api2app

First, I will test the API locally. To do this, I will run ComfyUI in CORS mode:

python main.py --enable-cors-header https://api2app.org

On the api2app website, I navigate to the "API" section and click the "Add New API" button. I open the "Raw Data" tab, create an object with the key "prompt" in the field, and paste the copied JSON. Then, I change the request method to POST and the URL to:

http://127.0.0.1:8188/prompt

I click the "Test" button in "Browser" mode and receive a response with the task ID in the queue:

For local use, you can use the standard ComfyUI API, but if you want to enable internet access, it's better to use an additional package: https://github.com/Comfy‑Org/comfy‑api‑proxy

I install the package:

pip install comfy-api-proxy

I start the proxy with an authorization key and CORS enabled:

comfy-api-proxy --enable-cors-header https://api2app.org --token=ea3092cf-7856-4ef8-988b-8f413f299c50

Now the request address is:

http://127.0.0.1:8189/api/v2/jobs

The key in the request body has also changed; instead of "prompt", you now need to use the "workflow" key:

You also need to add an "Authorization" header with the token I specified when starting the proxy:

Note that in "Browser" mode, the authorization field should not be private (the button with the lock icon).

I click the "Save" button and return to the "API" section. Now I need to create an API configuration to track the task status.

I create a new API configuration with the GET method and the following URL:

http://127.0.0.1:8189/api/v2/jobs/8fd2d6cb-0150-4d10-9b91-283eeef9ad5c

I click the "Test" button in "Browser" mode.

If the image generation is complete, the response will contain a URL to retrieve the result and a content ID (asset_id → id):

  "outputs": [    {      "node_id": "9",      "name": "0e2294e1-3666-466f-b579-8a8eb9318e81_00001_.png",      "type": "image",      "content_type": "image/png",      "size_bytes": 0,      "id": "eyJqIjogIjhmZDJkNm...",      "hash": null,      "url": "http://127.0.0.1:8189/api/v2/assets/eyJqIjogIjhmZDJkNm.../content",      "url_expires_at": "2026-10-18T14:12:40.658748+00:00",      "job_id": "8fd2d6cb-0150-4d10-9b91-283eeef9ad5c"    }  ],

The 3rd API configuration is for viewing the image. Request method: GET, URL:

http://127.0.0.1:8189/api/v2/assets/{asset_id}/content

asset_id is the content identifier from the response of the "/api/v2/jobs/" request.

The created API configurations need to be made public (or can be hidden).

Creating the Graphical Interface

It's time to create the web application with a graphical interface. To do this, I navigate to the "Applications" → "My Applications" section and click the "Create New Application" button.

I add a "Text Area" element and a button.

I will also add "Operation Progress" and "Image" elements.

Now I need to configure the input and output actions for the elements. I click the "Input Action" button for the "Text Area" element (image description).

In the input action settings window, I need to find the API configuration and select the field that contains the text prompt for image generation. In my case, this is the "Prompt.76.Inputs.Value" field.

For the "Button" element, the input action is the same API and the "Send" action.

I also need to add a hidden field named "Task ID". The task ID value will be sent to this field, and then a request will be made to get the operation result.

The output action for this field is: "comfyui - api - jobs post" → "id".
