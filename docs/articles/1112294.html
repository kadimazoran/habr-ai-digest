Developers of desktop software have struggled with packaging, signing, and notarization for years, while Anthropic has hidden all of this behind a single button. On November 24th, the beta version of Install as app was released for Claude on Mac and Windows. Now, artifacts can be installed as standalone applications with their own icons and windows.

What's Known

The 'Install as app' option is available in the Share menu, and according to TestingCatalog, it's also in the artifact header menu and the context menu. You need Claude Desktop version 6.28899.0 or newer. Installed applications do not work on Linux, the web, or mobile.

The beta is available for Free, Pro, Max, Ultra, Team, and Enterprise plans. On Team plans, the feature is enabled by default, but full computer access remains disabled until an administrator enables it. On Enterprise plans, the feature itself is first enabled by the owner. It is not available for HIPAA-ready organizations and hybrid deployments.

An API key is not required; the application runs under your account. Edits to an artifact are automatically reflected in the installed version, and builds and all requests to Claude are deducted from your plan's limits.

Among the demos from Anthropic employees are the Tern terminal with integrated Claude, the retro file manager Phosphor, and the Vitals performance monitor for the system tray.

Permissions and Limitations

  • By default, the application has the same capabilities as the artifact in the browser.

  • Additional permissions grant notifications, global hotkeys, a window on top of others, and an icon in the menu bar or system tray.

  • Full access allows running programs and reading, modifying, or deleting files without a separate prompt.

  • Consent is granted for a specific version; Claude will ask again after any edits.

  • The application will not open without an internet connection and being logged into Claude Desktop. If access to your account is lost, the programs will stop working in approximately 20 minutes.

Zero data retention (a mode where data is not stored) does not apply to these applications.

Expert Opinion

Anthropic explicitly states that applications are not verified before installation. Full access is only granted to your own applications, and on Team and Enterprise plans, also to colleagues' applications. The most interesting details are, as always, hidden in the fine print. Consent is tied to the version, but code that the application loads from other websites can change without a new prompt. Re-confirmation protects against edits to Claude, but not against an external script that might be updated on some random night. Therefore, if I were to grant full access, I would only do so for applications without external dependencies.

And another thing. Essentially, this is a thin client for your subscription, not offline software. The picture is that Anthropic is building an app store without a store, where each program lives only as long as your account. There are no independent security checks yet.

Conclusion

I'll set up the system tray monitor today; it takes five minutes. But full disk access will have to wait for independent reviews. The industry has long moved away from desktop to SaaS, and now it's returning to the desktop, only now even a self-written terminal won't launch without logging in 🙃
