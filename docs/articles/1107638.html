Apex Compute has released an open beta version of the Apex Neural Rendering frame generator. The tool works on top of the OptiScaler layer, replaces the standard NVIDIA DLSS Frame Generation call, and allows intermediate frame synthesis on GeForce RTX™, GeForce® GTX 16, AMD Radeon™, Intel® Arc™, and Apple Silicon chips.

Architecture and Platforms

ANR is a set of neural rendering tools positioned as a cross-platform alternative to NVIDIA DLSS. It includes three modules: super resolution, ray reconstruction, and frame generation. Currently, only the ANR FG frame generation component is available for download and testing, while the upscaling and denoising models for ray tracing are still in the training phase.

Interestingly, it boasts compatibility with graphics processors from different manufacturers and generations, including architectures without dedicated tensor cores. According to the project's official documentation, the ANR FG beta version supports the following platforms:

  • GeForce RTX™ 20, 30, 40, and 50 series graphics cards, as well as the GeForce® GTX 16 lineup;

  • Radeon™ RX 5000, RX 6000, RX 7000, and RX 9000 accelerators, as well as the Steam Deck portable system;

  • Intel® Arc™ A and Intel® Arc™ B series discrete graphics cards;

  • Apple M1 and newer System-on-Chips running macOS 26 and above (with Metal graphics API support).

On PCs, it supports Windows 10, Windows 11, Linux distributions, and SteamOS via the Proton compatibility layer.

Claimed Performance

Apex Compute emphasizes the compact size of its neural network model – 0.17 MB. According to the company's internal measurements on a GeForce RTX™ 5090 graphics card at 3840 × 2160 resolution, the ANR FG module takes 1.01 ms to synthesize one frame in double-generation mode, compared to 1.26 ms for standard NVIDIA DLSS Frame Generation. The video memory consumption was 214 MB versus 562 MB for NVIDIA's implementation (a reduction of approximately 62%).

In the performance summary tables across different modes and architectures, the company claims a speed advantage of up to 2.4 times for the frame generation stage compared to competing algorithms. In tests on AMD Radeon™ RX 7800 XT, Intel® Arc™ B580, and Arc™ A770 graphics cards, the ANR FG solution outperforms AMD FSR™ 3.1 in frame rendering time. On the AMD Radeon™ RX 9060 XT graphics card, the results are mixed: in 2X mode, AMD FSR 3.1 is faster, but in triple and quadruple frame generation, AMD FSR 4 with machine learning takes the lead.

To evaluate the visual quality of the synthesized frames, the developers provided examples from The Last of Us Part II Remastered and Hogwarts Legacy, as well as calculations based on objective video quality assessment metrics (CGVQM-5, ColorVideoVDP, and PSNR) in generation modes from 2X to 6X. In all published manufacturer tables, ANR FG values exceed NVIDIA DLSS performance. For example, in 2X mode, it claims 96.59 points versus 93.66 for CGVQM-5 and 33.84 dB versus 31.22 dB for PSNR.

Technical Nuances

Despite mentions of the project's openness, the neural network's source code has not yet been released on GitHub; only documentation and compiled beta version files are available in the repository. Apex Compute promises to release the code later.

ANR FG is integrated into games not as a native plugin, but through OptiScaler. The developers have released two build variants: a full package with a built-in modifier for a "clean" installation and a lightweight add-on for projects where OptiScaler is already in use.

For Windows, the standard Microsoft Visual C++ 2015–2022 Redistributable (x64) libraries are required. After copying the files to the game folder, simply enable standard NVIDIA DLSS Frame Generation in the settings – the layer will intercept the call and launch its algorithm. For Apple Silicon computers, a separate testbed is available to compare ANR FG over the Metal API with the built-in MetalFX technology.

All speed and quality measurements presented are based solely on Apex Compute's internal tests. How this method of library substitution will perform in real games when the CPU is the bottleneck, and whether artifacts will appear in dynamic scenes, remains to be verified by independent testers.
