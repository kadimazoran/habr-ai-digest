What it is and where the name comes from

Not long ago, the second version of the open-source music generation model, YuE2, was released. There are several open-source models, but YuE2 is currently one of the strongest.

According to the authors' own measurements on 192 songs, it outperforms open-source models like LeVo 2, ACE-Step 1.5, and SongBloom, and stays close to Suno. I haven't found any independent comparisons, so this is the authors' assessment.

As a result, GitHub is flooded with graphical interfaces for its Python scripts: input a style and text, get a track.

Therefore, I changed the initial name, yue-studio, to Partscaster. This term refers to a guitar assembled by hand from parts of different manufacturers: a body from one, a neck from another, pickups from a third. This best conveys the idea: not to generate a track from scratch, but to assemble and refine it to a result that differs from a purely AI-generated track.
