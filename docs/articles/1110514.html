How Pods and Virtual Servers Work

Our pods run from a container image. It can contain its own libraries, programs, and environment files; processes use the Linux kernel of the machine the container is running on. A VPS boots a guest OS with its own kernel. From the inside, it's a familiar Linux server: you install system packages, manage services, and configure startup after reboot. If desired, you can run containers within a VM.

Here, you can easily combine the advantages of these formats for your tasks: resource volume, allocation rules, and system access. 14 vCPUs instead of 8 provide more space for parallel CPU tasks. At the same time, the RTX 5090 in the pod is just as whole: switching to a VPS won't add VRAM. You manage the server yourself, with several OS options and any software.

In practice, we'd use a pod with pre-configured PyTorch for a one-off model run or ComfyUI for AI content generation. A VPS makes sense if you want to, for example, configure API and worker startup via systemd after a reboot. Additional vCPUs and RAM would be useful for video decoding, tokenization, or preparing multiple batches of data simultaneously. If the entire run is bottlenecked by the GPU, increasing the number of vCPUs won't speed it up on its own.

How Much Four Hours of Work Cost

Suppose you need one RTX 5090 for four hours of inference. IQHost's card, next to the most affordable VPS at 1,730 ₽ per day, states 72.08 ₽/h. However, the same public card shows two options: daily and monthly.

Platforms that calculate time differently also have different meanings for "terminate." Stopping a Python process, shutting down the machine, and releasing the GPU in the panel are three distinct actions. With Selectel, paid resources like disks remain after freezing. At immers.cloud, a normal shutdown still incurs GPU charges; the Shelve operation releases compute resources, while storage and a saved IP may continue to be charged. Clarify what survives a shutdown and check your billing log after your first short rental.

Our pods feature persistent storage (separate billing, survives pod shutdown with GPU), the size of which the user sets in the creation form. In VPS: Restart, Stop with resource and charge retention, and Delete - a button that terminates the machine rental.
