I'll try to explain my logic. If you just want to use a computer – use it. You don't need to install Linux. You've been using it somehow before.

If you want to quickly install a system and never touch it again, install Ubuntu and claim to be a seasoned Linux user. People will believe you, because Linux users from the internet don't always use the system themselves.

But if you want to learn something new, Arch will help you. I'll explain how exactly a bit later. For now, the main point: Linux itself is not difficult – it's more difficult and important to learn something new. Therefore, the system should be chosen based on how much it helps you learn.

If we imagine that we live in a cyberpunk world and everyone needs to choose a system to be installed in their head, I would choose Arch – and here's why:

  1. Arch Wiki is the best technical documentation in the Linux ecosystem. And not just for Arch. It's so detailed that even Ubuntu and Debian users use it. A beginner learning from it automatically gains a deeper understanding of the system than someone using Ubuntu's GUI tutorials.

  2. Manual installation is already a learning process. While installing Arch, you'll have to deal with disk partitioning, file systems, bootloaders (GRUB/systemd-boot), networking, locales, and CPU microcode. Ubuntu and Mint hide this behind an installer – half a year later, a person doesn't know the difference between EFI and MBR.

  3. Minimalism eliminates "magic." Ubuntu has many patches, default daemons, and snap wrappers – when something breaks, it's unclear where to look. In Arch, the system is close to its vanilla state: what you see is what works.

  4. The rolling-release and pacman combination teaches you to work with dependencies and package conflicts directly. Not through "just apt install and hope."

  5. AUR is much wider than Ubuntu and Mint repositories in terms of software currency. Especially for dev and security tools.

The fastest way to install Arch is to use the archinstall installer. As soon as you boot from the flash drive, select the first installation option:

A terminal will open:

Your learning begins right at this moment. First, you need to enter the correct commands. Second, you need to understand your specific situation. No matter how detailed our guide is, we cannot cover every possible system configuration because hardware components always vary.

The simplest idea. If your PC is connected to the network via an Ethernet cable, you can connect to the internet immediately. To do this, type the following command in the command line:

ping google.com

If the ping works – great! You are connected to the network, and we can continue. If not, you'll have to use another option. For this, you'll need a USB Wi-Fi adapter – something like this for 700–1500 rubles:

Your motherboard might have its own Wi-Fi adapter, but you might need to download separate drivers for it. A USB adapter, however, will work out of the box. Plug it into your PC and enter the following commands sequentially:

systemctl start iwd
iwctl

station list
station wlan0 scan
station wlan0 get-networks
station wlan0 connect [YOUR_WI-FI_NAME]
[YOUR_NETWORK_PASSWORD]

  • systemctl start iwd starts the iwd (iNet Wireless Daemon) service – a modern replacement for wpa_supplicant for managing Wi-Fi adapters in Linux. Without the service running, you cannot manage wireless interfaces.

  • iwctl launches the interactive iwd management console. After this, you enter a separate prompt like [iwd]#, where the rest of the commands are entered.

  • station list displays a list of wireless interfaces (stations) in station mode – usually your Wi-Fi adapter, e.g., wlan0.

  • station wlan0 scan initiates a scan of the airwaves for available Wi-Fi networks using the wlan0 interface. The scan itself doesn't output anything to the screen – it's just a "scan" command.

  • station wlan0 get-networks displays a list of networks found during the scan – SSID, signal strength, and security type (WPA2, WPA3, or open).

  • station wlan0 connect [YOUR_WI-FI_NAME] initiates a connection to the network with the specified SSID via the wlan0 interface. Replace [YOUR_WI-FI_NAME] with the actual network name (if the name contains spaces, enclose it in quotes).

  • [YOUR_NETWORK_PASSWORD] is not a separate command but a prompt to enter the password. After the connect command, iwctl will ask for the passphrase for a secured network, and you need to enter it in the field that appears.

Typical sequence of actions: start the daemon → enter the console → list interfaces → scan → list networks → connect → enter password.

If the connection doesn't establish after connect, check the status with the command station wlan0 show – it will display the current connection status and IP address.

Now, our task is to enter the commands:

pacman -Sy
Pacman -S archinstall
archinstall

pacman is the package manager. -Sy are flags to download all update packages. And by entering the command pacman -S archinstall, we download the archinstall installer. Then, we simply type archinstall and proceed with the installation.

Installation Configuration

Congratulations – you've reached archinstall. Now you just need to set the configurations. Use the up and down arrows to select an option, / to search for packages, and the spacebar for multiple selections.

What to set:

  • Mirrors and repositories → Optional repositories → multilib.

  • Disk configuration → Partitioning → Use a best-effort default partition layout → Your disk → ext4. I'm assuming you're installing the system on a separate disk, want to delete all data from it, and install a new system. If this is not the case, learn how to partition disks manually.

  • Bootloader → Grub.

  • Hostname → The hostname your PC will have. You can leave it as default.

  • Authentication → Root password → The root user's password.

  • Authentication → User account → Add user → Username → User account password → Yes (allow running root commands as the user) → Confirm and exit.

  • Profile → Type → Desktop → Hyprland → polkit. You don't need to change anything else here. Personally, I only installed opensource drivers and left sddm as the Greeter (it works more adequately on Hyprland for some reason).

  • Applications → Bluetooth → Yes.

  • Applications → Audio → pipewire.

  • Applications → Print service → Yes.

  • Applications → Firewall → ufw.

  • Network configuration → Use Network Manager (default backend).

  • Additional packages. Using / and the spacebar, I selected five packages: chomium, git, kitty, telegram-desktop, wofi.

  • Timezone → Region (using /).

Then, confidently press install and yes. And wait…

What's the Result

As a result, we have a system that has modest performance requirements, boots and runs on older machines, is convenient for working with various types of data, and has a number of cool features.

The first feature is the touchpad. It works like this:

  • One tap – left mouse button click

  • Two-finger tap – right mouse button click

  • Two fingers up or down – scrolling the page

  • Three-finger drag – moving windows around the desktop

  • Four-finger drag – switching between workspaces

The second feature is the desktop structure. We have ten of them:

Pressing the Super key will show you where and which workspaces are located. Each application opens in full screen. A second press will split the screen in half, a third will split one half in half again, and so on, following the golden ratio principle.

Another feature is the AI integrated into the terminal lines and the system core. If you run the command opencode in the terminal, you'll launch the AI assistant. It won't just answer in a chat but will also help you work with internal files. For example, my configuration was assembled with the help of AI.

An important characteristic is that it's opensource, meaning it has fully open code and doesn't leak your data anywhere. However, this doesn't exempt us from digital hygiene rules. Remember that!

Another killer feature is the hotkeys. There are really many of them. Firstly, if you press Super + /, a list of shortcuts that work with end-4 will open.

Secondly, you'll have access to my custom shortcuts.

And the last, but no less cool thing in my review is the panels:

The left panel works with an AI model based on your RAM (Llama). Everything depends on your hardware's power, but when working offline, it's an excellent assistant, albeit slower than online models.

The right panel is an analog of a central hub for all activities with settings buttons, notifications, and a calendar with reminders.

There are many more small details in the system: assistance with blocking and configuring sleep mode, working with backlighting for super-dark mode gamma adjustment, adapting the style to wallpaper colors, Dracula theme for a range of applications.
