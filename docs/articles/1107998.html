llama.cpp Parameter Categories

Common Params.

General parameters. Mostly completely overlap between all utilities (llama-cli, llama-completion, llama-server). The largest part of the parameters. In fact, this series of articles begins precisely with Common Params.

Link: https://habr.com/ru/articles/1108044/

Sampling Params.

Sampling parameters. For example, these are temperature, top-p, top-k, min-p, etc., but not only that. Sampling parameters also largely overlap between utilities. I must admit, I was very surprised when I looked more closely at the possibilities of controlling model behavior through sampling in llama.cpp.

Link: [material in progress]

Speculative Params.

Speculative decoding parameters. Settings related to the use of Draft models.

Reference: A Draft model is a small, fast model that works in conjunction with the main (large) model. It quickly predicts several next tokens and passes them to the main model for verification. If the prediction is confirmed, the main model accepts these tokens without generating them step-by-step itself, which speeds up the overall text generation.

Link: [material in progress]

Example-Specific Params.

Parameters specific to a particular utility. For example, llama-server has its own special parameters for working with the server part. These parameters are not present in llama-cli, llama-completion, etc. Each utility has its own specific parameters, some more, some less. A significant portion of specific parameters are found in llama-server. One might interpret the word "specific" as something rarely used, but this is not the case. This section lists, among other things, very important and necessary parameters for regular work.
