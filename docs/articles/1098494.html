How to Use Formulas in Tables

Let's say we have a table with data about product releases: feature names, launch dates, descriptions of new features. And I want to quickly find out in which month each feature was released.

I'll write a request:

Create a formula that takes data from the "Release Date" column and returns the launch month in the separate new column "Release Month" in full text format (e.g., "September", not "09").

The result looks like this:

Detailed assistant response:

I found the table "Test" with a field similar to "Release Date". Let me clarify the details — I'll check the exact field name and data format.

I found the table Test with the field Release Date (type: String, data in DD.MM.YYYY format). I will add a formula field Release Month that will extract the month number and convert it to its full name.

Formula: SWITCH(VALUE(MID({Release Date}, 4, 2)), 1, "January", 2, "February", ..., 12, "December")

Done! I found the date column in the Test table and added a formula field.

How it works

  1. MID({Release Date}, 4, 2) — extracts the 2-digit month number from the date in DD.MM.YYYY format (characters 4 and 5).

  2. VALUE(...) — converts the string to a number.

  3. SWITCH(...) — substitutes the full text name of the month.
