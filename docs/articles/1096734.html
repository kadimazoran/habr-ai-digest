This summer, I was looking for a Python developer position in AI: LLM, RAG, automation, remote work. I have about two years of experience, and manually applying to dozens of jobs a day quickly became tiresome. So, I wrote a bot that did it for me: it found vacancies on hh.ru, decided if they were suitable, wrote a cover letter, and applied.

The bot ran for two months, from June 17th to August 17th. During this time, it processed 1518 vacancies and sent 339 applications. The sample size is small: one person, one resume. However, I know everything about each application: the model's vacancy score, whether the email was sent, and which bot version it was written with.

Therefore, this will include not only the overall funnel but also how the results changed as I refined the bot.

How the Bot Works

Since December 15, 2025, hh.ru has closed its API for job seekers, so the bot operates through a regular browser (Playwright) using my logged-in profile. Twice a day, the Windows Task Scheduler launches it, and during each run, it does the following:

  1. Searches for vacancies using 14 queries: "AI Engineer", "LLM Engineer", "RAG", "Python FastAPI", "Python chatbot", and so on. Only remote positions, up to 6 years of experience.

  2. Filters out irrelevant postings using stop words: senior, lead, team lead, architect, 1C, intern.

  3. Sends the vacancy description to an LLM. The model assigns a score from 0 to 100: 85 and above means the role is directly about LLM or ML, 70-84 means Python backend where AI is part of the tasks, and below that is irrelevant. The bot only applies if the score is above the threshold.

  4. Writes a cover letter tailored to the vacancy: 4-7 sentences, with the first sentence highlighting my experience relevant to their main requirement. No "I am interested in your vacancy.".

  5. Applies. If the employer asks questions, it answers them based on my resume. If there's a test in the vacancy, it does nothing and forwards it to me via Telegram.

  6. Verifies that the application was actually sent and sends a summary card to Telegram.

The bot also reads chats with recruiters. It answers simple questions about experience and tech stack itself. Anything related to salary, relocation, personal data, or tests is sent to me as a draft for my decision.

I used the LLM via a Codex CLI subscription, so I didn't pay extra for the API. The state is stored in SQLite: which vacancies have been evaluated, which have been applied to, which chats have been read.

Where the Numbers Come From

The bot maintained its own database, but it lacked the crucial information: the employer's response. This is only available on hh.ru. The "Applications and Invitations" page provides statuses in JSON directly within the HTML, so I went through all the pages, including the archive, and matched the applications with the bot's database using the vacancy ID.

The data export is from October 20th. Two months have passed since the last application, so anyone who wanted to respond has likely done so. I calculated the outcomes as follows:

  • Invitation - Status is "Invitation" or "Interview".

  • Rejection - Status is "Rejection".

  • Opened and No Response - Application viewed, status unchanged.

  • Not Opened - Application not viewed by anyone.

The 339 applications include only those sent by the bot itself. Vacancies with tests that were forwarded to me, and my manual applications during the same months, are counted separately.
