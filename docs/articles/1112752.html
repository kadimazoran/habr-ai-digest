Thinkmine has released the general-purpose programming language Kobo for the .NET ecosystem in preview. Developers link the language's emergence to the spread of agent development and code generation based on specifications. The project is focused on collaborative development by humans and AI agents and is currently in its early stages, so the syntax may still change.

The authors formulated four design principles: native AI support, declaration consistency, reliance on a ready-made runtime, and self-documentation. Instead of third-party libraries for working with models, developers have added language constructs for prompts and tools.

Syntax

In declarations, the entity type is indicated by a colon on both sides, for example class:Name, function:Type Name(...), property:Type Name, var:Type name, or const:Type name. Attributes and modifiers are written in square brackets, and semicolons can often be omitted in regular single-line expressions. Code blocks are enclosed in curly braces.

[public, static] function:int Add(int left, int right)
{
    return left + right
}

[public] class:Box<T>
{
    [public] property:T Value { get; set; }
}

Variables require an initial value. Constants are defined using const:Type Name = value with constant expressions. Local variables, as well as class, struct, and record fields, can infer a fixed type using var name = value (such fields are private by default). For an explicit type, use var:Type, for dynamic binding — var:dynamic, and for type unions — var:union(...), for which the compiler generates a type at the namespace level.

Kobo also has nullable types with ?, the ?. operator, the ?? check, collections in square brackets, and queries starting with select (multi-line queries end with a semicolon). Functions support generics, asynchronous operations, extensions, delegates (parameter-types)->return-type, lambdas with a closure block for the last delegate, as well as preconditions requires and postconditions ensures with access to the returned value via result.

Language Features

The json type is built into the language: it supports properties, indexers, and implicit conversions to and from strings, and throws a JsonException on parsing errors.

var:string name = Input("Name: ")
Print("Hello, ${name}!")
var:string source = raw """{"name":"Kobo"}"""
var:json details = source
var:string text = details.StringValue
Print(text)

Prompts are declared using prompt:Type name { ... } in #:script scripts or asynchronous functions. Inside the prompt body, regular text works, Kobo expressions are substituted via ${expression}, and {...} remains a literal fragment.

#:script
[tool, description("Adds two integers")]
function:int Add(int first, int second) => first + second

prompt:int result {
    Use Add to calculate ${20} plus ${22}.
}
if result is int number
{
    Print(number)
}

Functions with the [tool] attribute are passed to prompts as tools. An AI function requires a configuration file kobo.ai.json to operate. Kobo programs can also be packaged as skills for external agents, for example, in Visual Studio Code.

Installation

The Kobo compiler is installed on top of the .NET 11 SDK, after which a separate file or an entire directory is compiled. The presence of a static Main will allow creating an executable file (if it is absent, the result will be a library).

dotnet tool install --global thinkmine.kobo.lang --prerelease
kobo build --source hello.kobo --output-directory ./build --name Hello
dotnet ./build/Hello.dll

The build, run, and generate commands accept the --source parameter with the path to a file or folder (the --recursive flag adds subfolders), and for .NET projects, use the thinkmine.kobo.lang.buildtools package. The --markdown flag in build and run compiles Markdown documentation from ### comments (by default, next to the source file, e.g., test.kobo.md), --publish-code saves the source listing, and the kobo generate command only creates a Markdown file.

kobo run --source app.kobo --markdown --publish-code -- Ada
kobo build --source app.kobo --markdown docs/app.md
kobo generate --source app.kobo --markdown output.md

You can learn more about the project in the GitHub repository. Extensions for Visual Studio Code and Visual Studio 2026 are also available for installation.
