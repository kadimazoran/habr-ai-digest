AI Platform Updated

On October 8, we held Selectel Tech Day, a large-scale Selectel conference. At it, we presented several product updates, including two new products for inference: Token Factory and Custom Inference.

Token Factory provides access to popular open-source models deployed in trusted Selectel data centers. Users will have access to GLM5.3-Flash, DeepSeek-V4-Flash, Qwen-3.8-Flash-Next, Qwen-3.8-27B, and other models with a unified OpenAI-compatible API. Payment will be calculated in rubles based on the volume of tokens used. All data is hosted and processed in Russia on infrastructure compliant with Federal Law No. 152-FZ. This excludes cross-border data transfer.

The second solution, Custom Inference, is planned for release by the end of 2026. The service will allow clients to choose from existing models or upload their own, including fine-tuned and custom versions, and deploy them on Selectel infrastructure. Ready-made configurations specifically designed for inference will be available for running LLMs. There will also be flexible management of model launch parameters for various use cases and load profiles.

Services for Data Management Introduced

The new set is designed for large and technology companies. It includes seven managed services that allow you to conveniently develop current data storage and processing systems: scale infrastructure without migration, architectural changes, or downtime.

  • Cloud for Trino — a distributed SQL engine that allows you to quickly query multiple sources at once: from S3 to DBMS.

  • Cloud for Hive Metastore — a centralized metadata catalog with support for Apache Iceberg — an open table format for Data Lakehouse, allowing structured data to be stored in S3.

  • Cloud for Redash — a simple BI tool for building dashboards and visualization.

  • Cloud for ClickHouse® — a columnar analytical system for high-speed queries with native Iceberg support in S3.

  • S3 Data Migration — a ready-made service for transferring data from external storage.

  • Hot S3 Storage — optimized for machine learning and analytics tasks.

  • Cloud for PGVector — a ready-made RDS service based on PostgreSQL, optimized for vector search in AI applications, for solving RAG tasks.

PostgreSQL v18 Added

It allows working with data on disks significantly faster. Up to this version, PostgreSQL used synchronous I/O (in read() and write() system calls) and delegated this work to the OS. Postgres used posix_fadvise — system calls that “advised” the OS on how the application planned to access the file.

By introducing asynchronous I/O (AIO), PostgreSQL gained two main advantages: control over sending I/O requests and support for Direct IO to perform copying between storage and the PostgreSQL buffer using DMA, without involving the OS.

New Unsloth Virtual Machine Image Added

Unsloth Virtual Machine is a pre-configured cloud server with tools for launching, fine-tuning, and deploying AI models.

The image from which the server is deployed contains:

  • Unsloth — an application for running and training models;

  • Docker — a platform for running containerized applications;

  • Jupyter — a unified development environment for working with Jupyter Notebook, JupyterLab, program code, and data;

  • llama.cpp — a utility for local deployment and operation with large language models (LLM);

  • drivers required for working with graphics processing units (GPUs).

In Unsloth Virtual Machine, you can train models both through the Unsloth interface and through Jupyter. You can use local models and connect to OpenAI-compatible APIs of external models.
