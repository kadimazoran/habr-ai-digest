Hello! Today I'll introduce you to the oh-my-pi (OMP) console agent, which isn't as well-known as cloude or opencode, but is very interesting in its capabilities, for example:

  • advisor (a reviewer model that looks over every move) has already appeared in cloude, but only with a paid model;

  • creation of sub-agents with their own rules, which can be run in a carousel (agents loop) without leaving OMP;

  • flexibility in working with pluggable LLMs, which can be assigned to sub-agents, organizing control over code writing, testing, and planning for your harness.

Installation and Launch.

You can install omp (Oh My Pi) in several ways, choose the one convenient for you and your OS:

Linux / macOS: curl -fsSL https://omp.sh/install | sh

Windows, PowerShell: powershell irm https://omp.sh/install.ps1 | iex

or simply npm install -g @oh-my-pi/pi-coding-agent

Launching with LiteLLM, Ollama, LM Studio, or llama.cpp

If you are using local models through the LiteLLM proxy, launch it like this:

LITELLM_BASE_URL=“http://<ip:port>/v1” omp

If the proxy requires an API key:

LITELLM_BASE_URL=“http://<ip:port>/v1/ ”
LITELLM_API_KEY=“your-key” omp
