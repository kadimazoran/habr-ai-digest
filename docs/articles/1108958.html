Chinese delivery platform Meituan has released the weights for its multimodal MoE model LongCat-2.5, boasting approximately 1.6 trillion parameters with about 48 billion active per token, under a permissive MIT license. Notably, the model was trained without Western accelerators, and its official deployment guide contains no instructions for NVIDIA GPUs. The weights are now available on the Hugging Face repository.

LongCat-2.5 leads only in the BrowseComp test (91.9 points) — this is a benchmark for deep internet information retrieval where the model searches Google, opens pages, and gathers complex facts. However, this result was obtained in Meituan's own closed environment, and in such tests, the final score heavily depends on the search engine integrated with the neural network.

The jump in DeepSWE (from 9.7 in the previous LongCat-2.0 to 64.6) is interesting — this is a test for full-fledged development where the model must independently analyze a third-party repository, find the cause of a bug, and write a working patch. In the latest technical report, the developers explained how they achieved this growth: the model was fine-tuned on real pull requests from GitHub within completely isolated containers. To prevent the neural network from "cheating" and looking up готовые answers, its internet access was disabled, commit history and cache were cleared, and a separate LLM acted as a verifier to ensure the correctness of the solution.

Nevertheless, in this task, the model still lags behind DeepSeek and OpenAI by 8–10 points. And in Terminal Bench v4.0 — a test of the ability to independently operate in a Linux command-line environment (setting up environments, deploying, fixing configurations) — it falls short of Opus by 15 points.

Can you run it yourself?

To run it locally, Meituan describes a cluster of 194 Huawei Ascend Atlas A2 series accelerators: two are used for image processing, 64 for prefill, and 128 for decode.

The guide is located in the longcat-2.5-npu branch of the SGLang-FluentLLM repository; there are no NVIDIA GPU or VRAM requirements in the official model card. For those operating outside of China, this means the model is accessible via API, or one will have to wait for the architecture to be ported to standard vLLM and SGLang branches for CUDA.

The quantized W4A4 version with four-bit expert weights and activations, according to Meituan, speeds up prompt processing by 43.3% and generation by 42.77% compared to the eight-bit version while maintaining accuracy. The context window via API is заявлен up to one million tokens, and response generation up to 128,000.

However, an unpleasant nuance has already been noticed in the multimodal part. Via API, the model accepts video files exclusively via a public URL link, so directly feeding it a private screencast of a bug without workarounds will not be possible.

How much does it cost?

The API supports standard OpenAI and Anthropic formats, and the model connects seamlessly with Claude Code and Codex. The price during the promotional period is a bargain — about €0.27 per million input tokens and €1.07 per million output tokens, but the promotion is limited in time. For comparison, Alibaba's Qwen4-Max, released on Monday, costs $1.50 and $4.50 per million input and output tokens, respectively, according to TheNextWeb, with closed weights.

What remains unclear

The model size in the model card and in the Hugging Face metadata is still listed differently (1.6 and 1.8 trillion parameters) — the authors have not explained this discrepancy, likely due to different counting methods for auxiliary visual modules. Also, there are no real community measurements yet on quality degradation with the maximum context of 1 million tokens.

The open weights have a strong code variant under MIT with a cheap API at launch. It should be tested exclusively on your own repositories — BrowseComp measurements are a poor indicator here.
