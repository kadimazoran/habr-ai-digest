I propose a method to download AI-generated 3D models with textures after free generation, for reviewing the results in any 3D graphics software. Websites offering free generation, usually, do not offer free export of generated 3D models. After uploading an image and generating a 3D model, the export option will be inactive unless a subscription is purchased.

But if you still need to download it, here's how you can do it without touching the "Export" button.

Without much deliberation, I took a photo from the internet as an example.

Next, I sent this photo to the AI. Using tripo3d.ai as an example.
Modern AIs can create 3D models based on several photos of an object, but in this example, I only used one photograph.

The 3D model is ready, and so are the textures. Clicking the "Export" button prompts the site to offer a subscription.

Next, close the window; the "Export" button is not needed. Since the generated 3D model has already been created by the site and is in GLB format, this model can be downloaded by doing the following:

  1. Press "F12"

  2. Go to the "Network" tab

  3. In the line below, type .glb (or .gltf)

  4. Refresh the page by pressing "F5"

  5. Below, a file with the 3D model "file.glb" will appear

  6. Right-click on the file and then select "Open in new tab"

The 3D model in GLB format will be downloaded and will already contain the textures. I use 3ds Max, and it doesn't support GLB files by default. To resolve this, you can install the glTF/GLB import and export plugin.
https://github.com/KhronosGroup/glTF-3ds-Max-Plugin

In my case, I cannot import the 3D model obtained from Tripo3d.ai into 3ds Max due to an error, which I believe is related to compression issues. For this, the file needs to be re-saved first. You can use https://gltf.report/. Import the file there and select compression — Draco. Then, you can export the file without problems and open it in 3ds Max for review.

After this, you can, for example, export the 3D model as an OBJ file or another popular format for subsequent editing in Zbrush. Perform auto-retopology there and refine the 3D model, as "glitches" are inevitable, especially considering that the generation was based on a single photograph. But since this is no longer about review, it can be revisited in another situation.
In any case, creating 3D models with AI significantly simplifies the work of a 3D modeler. On the other hand, since the 3D model is created faster and easier, the value of such work for the client decreases, which can affect the payment for labor.

I checked the same thing using hi3d.ai as an example. The result is the same, only without import problems, due to unsuitable compression.

If there are no problems with payment or subscription. And no desire to further examine the 3D model and textures, then of course, you can do it more simply, without these manipulations. Moreover, such sites offer only a limited number of generations per account, and creating dozens of accounts to download 3D models is possibly not a very suitable way to obtain 3D models.
