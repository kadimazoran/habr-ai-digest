Extracting the Style Genome in Chat GPT: From Reference to Ready Skill

Creating a single image from a reference is easy. It's much harder to create a series of images with changing objects and plots while maintaining a consistent visual style. In this article, we explore how to make image generation more predictable in style. Learn more about style genome.

Creating a single image from a reference is not difficult. It is much more challenging to create a series of images where objects and plots change, but a single visual style is maintained.

The difficulty usually lies in trying to replicate the entire reference: along with the object, composition, lighting, and plot. As long as the new picture resembles the original, everything works. But problems arise when we try to replace an object with a person or create a series of different images within a given concept. The model begins to gradually revert to its basic image generation habits, and the visual style becomes distorted and changes over time.

Therefore, I use a different approach. First, I ask for a detailed description of the reference, then I separate the style from the content, find its core, assemble a master prompt, test it on different objects, and finally, I turn the entire method into a skill so it can be applied in subsequent image generations.

I call this the style genome.

A little terminology.
Genome — a complete description of the visual language without a specific plot.
Core — mandatory features without which the style loses its recognizability.

Skill — within the framework of this method, a saved instruction based on a ready-made master prompt that allows reproducing the found visual style when changing objects and actions.

Step One. Detailed Image Description

First, I upload the reference and ask for a detailed description as a prompt.

For example:
Describe the image as a detailed prompt: object, composition, shapes, colors, lighting, materials, textures, mood, atmosphere, and rendering method.

At this stage, it is very important not to omit anything. We need to analyze the image in maximum detail and understand what it consists of. It is best to avoid generalizing words like "vintage," "cinematic," or "atmospheric." Such words describe an impression but do not explain what creates it.

Instead of "vintage illustration," it is more useful to get a specific set of features: a limited palette, a warm paper surface, noticeable grain, flat shadows, absence of gradients, slight displacement of print layers.

That is, we describe not the impression itself, but highlight all the stylistic features that form it.

Step Two. Pure Style

In the next step, I ask to remove everything related to the specific plot and object from the description.

For example:
Remove specific objects and plot. Leave only the visual style, composition, palette, lighting, materials, textures, mood, and rendering method.

Suppose the original image is a night gas station. We don't need the gas station itself, nor the neon sign on it.

Night might only relate to this specific plot.

But if the light is depicted as separate color spots without soft glow, and shadows are formed as flat spots without gradients — these are already properties of the visual language.

The result should be a description not of what is depicted, but of how it is depicted.

Step Three. Core

And since the description can still be quite long after cleaning, I ask Chat GPT to highlight the mandatory features.

For example:
Identify the features without which this visual style will cease to be recognizably reproduced. Separate them from characteristics that can be changed.

Thus, two groups emerge: the core, which must always be preserved, and variables — what can be changed without destroying the visual language.

For example, a limited palette, absence of outlines, characteristic shadows, and grain can be the core. While the angle, composition density, or the amount of print layer displacement can be variables. This is important because we need the style itself, not the same image template.

Step Four. Master Prompt

After this, I ask Chat GPT to assemble a master prompt based on the result obtained.

For example:
Create a universal master prompt. Denote the changeable subject as [Subject], and add [Action] if necessary. Keep all mandatory visual style features constant.

As a result, the specific object disappears from the permanent part of the prompt. The structure remains approximately: [Subject], [Action]. And then — constant rules for color, light, shape, texture, materials, and rendering.

Now, you can substitute a person or a bird in [Subject], and specify the action for this object in [Action] if necessary. If the genome is found correctly, the visual language should be preserved.

Step Five. Protection Against Drift

This step is needed to prevent the model from gradually reverting to its usual generation solutions.

For example:
Identify what should be avoided during image generation so that the result does not go beyond this visual language.

If the style is built on flat shapes, volumetric gradients and realistic lighting can become a problem. If the style has no outlines, the model should not add them independently. If our genome has a rule of four colors, then there should not suddenly be more or fewer.

Thus, we have an additional safeguard against style drift.

Step Six. Genome Verification

At this stage, we need to test the master prompt on the most diverse objects. For greater accuracy, do not test a car on another car or an orange on a lemon. Such objects are too similar and belong to the same category.

For example:
Test the master prompt on several maximally different objects. Compare the results with the original reference and with each other. If the visual style begins to drift, refine the master prompt by strengthening the mandatory core features. After testing, provide the corrected version.

Each new subject tries to reintroduce its usual rules corresponding to its type and properties. If the core is preserved after testing, the genome works. If any feature is lost or works unstably, its formulation needs to be clarified, and the test should be repeated.

Only after this check can the master prompt be considered functional.

Step Seven. Skill Creation

And here begins the final part of the method. Up to this point, we have manually gone through the entire chain and obtained a working master prompt. But inserting it anew each time and repeating all the style rules is not very convenient. Therefore, the ready-made master prompt can be saved as a skill and used in subsequent generations.

For example:
Create and install a skill based on the ready-made master prompt. Save the style core, variables, and drift protection rules. When generating, I should be able to change the object and, if necessary, the action, while maintaining the constant part of the visual style. Do not add solutions that contradict the genome.

Why Turn This Into a Skill at All?

A master prompt solves one task: it allows reproducing a specific found style. A skill solves a task at a higher level: it saves this master prompt as a ready-made instruction that can be reused to generate different objects. This is an important distinction.

Master prompt — is the result of work.
Skill — is a tool that allows convenient use of this result.

Therefore, the ultimate goal of the method is not to describe one style well once. The goal is to build a convenient, repeatable process that can be launched again and again, saving effort and time on preparing each new generation. The method is saved and ready for reuse.

Where Text is Insufficient

Not every visual style can be fully described in words.

For example, color and light are usually conveyed quite well. But a peculiar line or form plasticity can sometimes be difficult to express solely through text.

In such cases, the genome remains the textual basis, but you can additionally use the visual reference itself and other methods of image linking.

It is also important to remember that the same prompt can yield different results in different neural networks. For example, you created and tested your style in ChatGPT, and then decided to use the same prompt in another neural network. Even if the wording remains the same, the result may differ slightly.

Therefore, it is better to separately check how your style works in each tool and, if necessary, save your version of the prompt for it. This way, you won't have to set everything up from scratch each time.

In Conclusion

When I started this experiment, I wanted to understand if it was possible not just to replicate a favorite reference, but to preserve its visual language when generating completely different objects.

In the process, it became clear that a single detailed prompt is not always enough for this. I had to return to the results, compare images, notice which features were preserved and which gradually disappeared, and refine the wording. It was from these observations that the method described above was formed.

In practice, I managed to get a series of images where different objects retain a common visual language. This does not mean that the genome guarantees the same result with every generation. But it provides a clear basis to work with, instead of starting style setup from scratch every time.
