What Happened

On September 4, 2026, autocompletion and the agent stopped working for Russian users of Cursor.

Anysphere has not published an official announcement. An indirect sign of a planned decision is that Cursor's Terms of Service were updated on September 3, 2026, the day before the shutdown. They include section 17.5, "Export and Trade Controls."

You must comply with all applicable trade laws, including sanctions and export control laws. The Service may not be used in or for the benefit of, or exported or re-exported to (a) any U.S. embargoed country or territory or (b) any individual or entity with whom dealings are prohibited or restricted under applicable trade laws.

Cursor has followed the lead of OpenAI and Anthropic, bringing its actual service behavior in line with US export controls. It was already impossible to pay for a subscription from Russia, as payment processors rejected cards. Now, even the free scenario is unavailable.

Using a VPN works only until your account is banned, as using the service from a restricted jurisdiction violates these very ToS.

How Tools Were Selected

This review includes only those tools that are accessible from a Russian IP address without a VPN and can be paid for in rubles using a Russian card. Anything requiring a proxy, a foreign card, or an account with a foreign address has been excluded from this selection. Based on the experience of the last two years, such tools can be disabled at any moment by someone else's decision.

Next, we present five options and one DIY solution.

1. Aether Lab

A 1C development environment in the browser with an AI agent. In addition to code, it handles queries, configuration analysis, and primary document recognition.

Format — A full-fledged IDE in the browser. It features a workspace file tree, a Monaco editor with BSL language support, a built-in diff editor with change navigation, tabs for parallel sessions, and panels for chat and queries in a single window. The environment connects to the information base via an external processing file (.epf) that provides code and metadata dumps.

Pricing — Free trial for 2 days, then plans starting from 1990 ₽/month, with corporate subscriptions available.

Pros

  • Nothing to install or update locally; the environment opens in the browser on any machine.

  • Full support for 1C specifics: code and extension management, syntax assistant, validation, and query execution.

  • Higher-tier plans allow connecting your own subscriptions.

  • External processing files can be assembled without the Configurator; includes scheduling, edit history, and diff features.

  • Numerous out-of-the-box integrations: task trackers, CRMs, email, telephony, etc.

  • Beyond code, the same subscription offers configuration analysis, technical specifications, dashboards, and a custom agent builder.

Cons

  • Autocompletion in the editor works based on language and metadata; AI-powered next-line suggestions are not offered as a ghost feature like in Cursor.

  • No integration with 1C:EDT.

  • Cloud processing means code and metadata are sent to the service's servers, requiring approval or corporate plans for secure environments.

Who it's for — Teams using the Configurator and mixed teams of developers and analysts who need AI for their specific configurations and tracker tasks.
