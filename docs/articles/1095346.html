When working with an AI assistant, a significant amount of time is spent on explanations: here's the code, here's the configuration structure, here are the related objects. Infostart MCP allows the assistant to obtain part of this information itself, access the syntax helper, and use BSL code checking tools. The Infostart Resource Center decided to test how this works on typical 1C specialist tasks.

The first results were collected in an article on Infostart. Developers, analysts, an architect, a tech lead, and department heads participated in the pilot. They tried developing integrations, modifying reports, preparing technical specifications, finding causes of problems, and checking contractor changes.

Among the tasks were integrating 1C:UT 10.3 with Bitrix24, adapting the "Purchase Book" for Enterprise Accounting 2.0, and preparing technical specifications for generating an advance invoice. The assistant, using MCP, found the necessary objects and procedures, clarified syntax, and checked the code. Some tasks were brought to a working result, while others only yielded hypotheses that still needed verification.

There were challenges as well. First, the environment and access to configurations needed to be set up. Then, participants encountered errors when accessing MCP services and limitations of the tools. It became clear how important it is to provide the assistant with the correct source code: if it analyzed a different configuration, its conclusions were not suitable for solving the task.

Automatic effort estimation was also tested separately – a stable result could not be achieved here. Some analytical and architectural tasks also remained unfinished.

Even successful experiments required specialist attention. For example, the integration with Bitrix24 was brought to a working solution, but errors occurred during the process, the causes of which the assistant identified incorrectly. Access to code and metadata helped it understand the task, but its recommendations still had to be verified by a human.

Based on the pilot results, MCP performed best when working with a specific configuration and its source code: it helped find the necessary information and perform initial analysis. How useful this approach will be depends on the task itself, the environment setup, and the chosen AI model.
