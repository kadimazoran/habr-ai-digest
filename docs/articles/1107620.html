On November 16, just five days after the preview version was shown, Alibaba released the full flagship model Qwen4-Max. This is a multimodal MoE giant with 2.4 trillion parameters (71 billion active) and a context window of 1 million tokens, optimized for complex coding, agent mode operation, and project prototyping – from frontend to 3D games. The model is focused on programming, solving complex multi-level tasks, and creating projects, including games.

The model weights are currently closed, and it cannot be deployed on your own computer. Access is only available through the cloud and API (although developers promise to release more compact versions of the Qwen4 lineup in open source later). Below, we analyze the release architecture and look at the benchmarks.

After the full release, the model adopted pay-as-you-go token usage through Alibaba Cloud. The cost is $1.5 per million input tokens and $4.5 per million output tokens, which is 25% cheaper compared to Qwen3.8-Max.
The Token Plan is still available – the Lite tariff costs $6 and includes 20,000 credits, and for new users, the subscription is available for $3.

Benchmarks

With the release of the full Max model, benchmarks have also been released.

In the DeepSWE v1.1 benchmark, which tests programming skills in an agent environment, the model leads with a score of 75.7 points compared to Claude Opus 5.5's 74.2 points. In Terminal-Bench 4.0, a benchmark evaluating command-line operation, Alibaba's flagship model scored 48.5 points against Kimi K 3.1's 67.2.

For example, let's look at the HLE (Humanity’s Last Exam) benchmark, which deals with complex scientific and technical tasks. The model showed a respectable 51.7 points, and in Agent’s Last Exam, it scored 46.7 points.

It's worth noting the optimization of token usage – in the internal Work360 benchmark, which tests the model's ability to handle complex multi-level tasks, Qwen4-Max uses approximately 125,000 tokens in Xhigh mode and scores 52.7 points, compared to 165,000 tokens and 47.7 points for Qwen3.8-Max.

In Terminal-Bench 4.0, Qwen4-Max uses almost half the tokens compared to the 3.8 version, which scored 37.8 points.

Conclusions

Alibaba has released the long-awaited benchmarks, comparing Qwen4-Max with top competitors and the previous Qwen3.8-Max. The main drawback of the report is that we were not provided with a comparison between Qwen4-Max Preview itself and the Max version released today. Therefore, it's impossible to assess the real growth in the model's capabilities and quality since the preview.

Currently, the model cannot be deployed on your own computer to utilize its full power. Although token usage has been optimized, this is more of a trend among all model developers rather than a desire by labs to earn less from us.

In general, releasing the full Max version just five days after the Preview is classic AI marketing. It's clear that a 2.4 trillion parameter model cannot be retrained in such a short time; at most, inference bugs were fixed, and system prompts were fine-tuned.
