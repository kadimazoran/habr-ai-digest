Embeddings, in simple terms, are just a mapping of some object that a neural network needs to work with to a set of numbers—a vector. The number of coordinates in the vector is the dimensionality of the n-dimensional space in which this vector (embedding) is defined. You can read more about embeddings in this beginner-friendly article.

Typically, when discussing embedding visualization (or, as we now know, n-dimensional vectors), it refers to mapping a set of these vectors into a two- or three-dimensional space with dimensionality reduction. The article "How Dimensionality Reduction Algorithms Can Deceive You", for example, discusses the main methods for mapping n-dimensional vectors.

These mapping methods are designed to show the position of several vectors in space and assess how close or far apart the vectors are. It's also possible to identify groups of vectors that are closer to each other (based on some formula calculating the distance between vectors) than to other vectors in the set.

However, for human analysis of vectors, it can also be useful to visualize an individual vector. In this case, it's possible to compare the 'shape' of objects representing vectors and infer the proximity of compared vectors based on the similarity of these shapes. It would also be interesting to visualize a vector during neural network training iterations and observe changes in the vector's 'shape' as the model trains. This approach avoids the data loss drawback of commonly used dimensionality reduction methods for vector mapping. To be objective, we must admit that we gain another drawback—difficulty in visualizing a large number of vectors. But for a pair (or a few) vectors, this visualization method is quite acceptable.

As a basis for mapping a vector into three-dimensional space, we decided to use a standard three-dimensional sphere. However, the radius of this sphere will be variable. Its value at each point on the sphere will represent the value of one of the coordinates of the n-dimensional vector we are visualizing.

We will use the locally run model "qwen3-embedding:latest" and the ollama library as the source for vector coordinate values. The installation and setup of a local LLM will not be described in this article. We will use the numpy library to form coordinate arrays, and for rendering three-dimensional objects based on the calculated coordinates, we will use the plotly and dash libraries.

The main sequence of actions will be as follows:

  1. Obtain the vector value for the object of interest (in the case of LLMs, these will be words)

  2. Calculate a set of three-dimensional coordinates for the object

  3. Visualize the obtained coordinates in three-dimensional space.

Obtaining the vector for a selected word word by calling the ollama API might look like this:

import ollama
import numpy as np

response = ollama.embed(
    model='qwen3-embedding:latest',
    input='word'
)

vector = response['embeddings'][0]

Next, the obtained vector vector needs to be converted into a matrix for ease of coordinate calculation. In our case, the dimensionality of the vector returned by the LLM qwen3-embedding:latest is 4096 coordinates. We transform it into a 64 x 64 matrix (64 x 64 = 4096) of values.

r = np.reshape(vector, (64, 64))

And then we can calculate the three-dimensional coordinates of the object that will represent our vector:

u, v = np.mgrid[0:2*np.pi:64j, -np.pi/2:np.pi/2:64j]
x = r * np.sin(u) * np.cos(v)
y = r * np.sin(u) * np.sin(v)
z = r * np.cos(u)

In the example above, we first form a set of parameters u and v (which is a set of angle values—spherical coordinates) necessary for calculating the three Cartesian coordinates x, y, z of the object. Then, using the numpy library, we calculate the set of Cartesian coordinates for the object's points.

After this, all that remains is to visualize this set of coordinates in three-dimensional space.

To demonstrate the results of the described method for visualizing n-dimensional vectors, several images have been prepared. The first image shows visualizations of the word "death" (left figure) and "life" (right figure).

Looking at the provided image, we can note the following:

  1. The shape of the objects resembles a sea urchin. Therefore, this method of visualizing n-dimensional vectors in three-dimensional space can be called the "sea urchin" method.

  2. The objects have distinct, longer "spines." These "spines" correspond to large values of the vector's coordinates.

  3. The number, size, and direction of the long "spines" differ significantly between the objects visualizing the words "death" and "life." That is, based on the shape of the objects, one can judge their degree of similarity and infer how close (more similar objects) or far apart (less similar objects) the vectors corresponding to the objects are.

The following conclusions can be drawn:

  1. The described method for visualizing n-dimensional vectors in three-dimensional space indeed allows for the visualization of objects corresponding to these vectors, and this is done without loss of coordinates.

  2. The resulting objects resemble sea urchins, characterized by longer "spines" that represent vector coordinates with large absolute values. These coordinates are likely more significant for the object (word in our example) corresponding to the vector.

  3. Objects can be compared by their shape. The more the objects differ (in the number, direction, and length of spines), the farther apart the vectors corresponding to the objects are located.
