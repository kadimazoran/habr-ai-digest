Anthropic has three bots with different tasks: one collects texts for training AI models, another indexes pages for Claude's web search, and a third visits when a user asks to read a page. Each can be blocked separately in robots.txt, but sites often block the ones they depend on. Crawl Readiness checked the top 1000 sites in October 2026: Claude-SearchBot is blocked by 63 out of 569 sites with a robots.txt, meaning one in nine. A page only becomes a source for Claude if it's seen by the search engine it uses and if the search and user bots are allowed on the site. The training ClaudeBot has little impact on this, so if the goal was just to prevent text from being used for training, blocking only that bot would suffice.

When Claude searches the web and when it answers from memory

Claude decides on its own. In its developer announcement, Anthropic describes it this way: if a search would be helpful, Claude formulates a query, reads the results, and responds with links to sources. As of May 27, 2025, web search is available on all plans worldwide, and the new interface doesn't even have a toggle: according to October 2026 documentation, Claude searches when it's helpful. It doesn't search often. In the State of AEO 2026 study by Josh Blyskal and Jasman Singh, Claude enabled search in 36.6% of cases, slightly more than one in three. In other responses, it answers from memory, and a page cannot become a source in those cases.

Forcing a search is done by including the phrase Search the web or Use web search in the query, as Anthropic itself advises. Reading a page via a user-provided link is called web fetch by Anthropic: here, Claude doesn't search for anything; it opens exactly the page it was given.

Which search engine does Claude use, and why do measurements point to Brave

Anthropic does not disclose Claude's search provider, but traces lead to Brave Search. Simon Willison noted that since March 19, 2025, Brave Search has been listed in Anthropic's Trust Center as a subprocesser (recounted in the Crawlmind blog). Complete SEO compared results for 1,481 queries: 87.8% of the pages retrieved by Claude's search were in Brave's top 10, while only 45.6% were in Google's top 10 for the same queries. For 52 clients of the same company, the difference is even more stark: Claude cited a site from the 1st–3rd position in Brave in 92% of responses, and a site outside the top 20 in only 12%.

The overlap in results doesn't prove causation, and Anthropic itself hasn't confirmed Brave. However, based on these numbers, a site outside Brave's top 20 can hardly expect to be cited by Claude.

Which Anthropic bot is responsible for what, and what happens if it's blocked

Only ClaudeBot affects training; two others are responsible for visibility in Claude. The table is compiled from Anthropic's April 7, 2026, documentation for site owners.

Anthropic does not recommend blocking bots by IP: they won't be able to read robots.txt, and the denial might not work. Denials are configured in robots.txt, separately for each subdomain.

How to block ClaudeBot in robots.txt and not block the bots Claude's answers depend on

The fragment blocks the site only for training and explicitly allows the other two bots.

User-agent: ClaudeBotDisallow: /User-agent: Claude-SearchBotAllow: /User-agent: Claude-UserAllow: /
