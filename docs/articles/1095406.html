In this article, I will show you how to choose a suitable model, configure it correctly, and avoid common integration mistakes.

aish is a terminal AI agent of the SELECTOS operating system. Since version 0.3, it has become possible to add models: locally deployed or from third-party providers. Let's see how to connect a model to the agent step by step — and for example, we'll take GLM-5.2 from Selectel's AI router.

AI router is a unified access service to generative language models. It allows you to use models from different providers without separate integrations, vendor contracts, and currency payments. You can get access to models in a few minutes following the instructions.

Compatible Models

With aish, you can use models that support the OpenAI Chat Completions API and Tool Calling. For example, in the AI router, you can see the presence of tool and chat right in the list of models.

Adding a Model Through the Interface

Step 1

Open the Commands menu by pressing Alt+C or F9. On macOS Terminal, use the Option key instead of Alt.

In the Commands menu, the Select model option is selected by default — press Enter.

Step 2

In the Models window, use the ↑↓ or Tab keys to move the focus to the + Add button in the lower right corner of the window and press Enter.

Step 3

Specify the provider in the Select provider window. In our example, we will look at how to connect the GLM-5.2 model from Selectel's AI router.

An LLM provider is a company or service that provides infrastructure for working with artificial intelligence and grants access to it through a software interface (API) or web interface. To connect to a provider's models, you need an API key and the provider's URL. Typically, the provider provides this when you sign up for a subscription. If you are connecting a corporate model, this information is provided by the service administrator.

If this is your first time adding a model, the list of providers will be empty. The New provider option will be selected in the Select provider window — press Enter.

If you have added models before and want to add another model to a previously registered provider, select it using the ↑↓ or Tab keys and press Enter.

If you want to add another provider, select the New provider option and press Enter.

Step 4

After selecting the provider, fill out the Connect Models form. You can paste data from the clipboard. Navigate through the fields using the ↑↓ or Tab keys.

If you are creating a new provider, make sure to fill in all the fields in the form — we'll explain how to do this below. If you are adding another model within an already connected provider, enter only its identifier, press Enter, and then Save. The model input field will be in focus immediately.

How to fill in the fields

  • Provider name — the name of the provider. Enter it in a free format, as you prefer. We recommend choosing short names; in our example, it's AI-router.

  • Provider URL — the network address that points to the provider's API. The value has a link format: https://ai.provider.example.ru. In the AI router, this link is located within the router card in the Overview → Base URL section.

  • API key — a private access key to the provider's service in UUID format, possibly with prefixes depending on the provider. In the AI router, the API key is displayed once when the router is created — copy it immediately. If you missed it or forgot to do so, add a new key in the Keys and Limits tab.

  • Models (ID) — model identifiers in the format qwen3.6-27b, glm-5.2, etc. We recommend copying the exact identifier from the provider's panel.

Important: after entering the model identifier, be sure to press Enter. The model line should appear below the input field. You can add multiple models available to you at once.

If you decide to delete a model within a provider, focus on it and press the Delete key (or Option+Backspace on macOS).

When you finish filling out the form, save the changes. To do this, move the focus to the Save button using the ↑↓ or Tab keys.

Please note: to save changes, it is important that all fields in the form are filled and at least one model is specified. If there is a save error, return the focus to the field and fill it in. In the case of a model, press Enter so that it is added to the list below the input field.

Step 5

After saving, you will return to the list of models. Select the model from the list using the ↑↓ or Tab keys and press Enter.

Adding a Model Through a Configuration File

You can also add a model or provider through a configuration file using the method described below.

Note: we recommend adding providers and models, as well as editing data, through the TUI. However, deleting a provider through the TUI is not yet supported — it is only available by editing the configuration file.

Example command for the nano editor:

nano /root/.local/share/aish/llm_registry.json

Example configuration file:

{  "map": {    "AI-provider": {      "api_key": "exampleAPIkey1",      "endpoint": "https://provider.example.ru",      "models": [        "qwen3-6-27b"      ]    }    "AI-router": {      "api_key": "exampleAPIkey2",      "endpoint": "https://ai.provider.example.ru",      "models": [        "z-ai/glm-5.2"      ]    }  },  "selected": [    "aish",    "aish_model"  ]

Conclusion

We have covered two ways to add a model to aish: through the interface and a configuration file. You can add other models using the same principle — from the AI router or locally deployed ones. It is important that the models support the OpenAI Chat Completions API and Tool Calling.
