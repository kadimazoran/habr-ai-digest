At some point, I made the head of my AI office swear at his subordinates.

Not for a laugh. It's just that before that, my agents could produce mediocre results very politely, very diligently, and sometimes very expensively.

After such a boss appeared, the office's behavior changed noticeably. And my first thought was quite simple: well, it's clear, neural networks just need a tougher boss.

As it turned out, it's not clear at all.

"Overall, everything is fine"

You've probably seen this.

You give Claude a text and write:

Check the text. See if there are any errors or shortcomings.

In response, you get the familiar:

Overall, the text is well-structured, the main idea is clear, but there are a few points that could be improved...

This "overall, everything is fine" started to drive me crazy at some point.

Not because I want the neural network to necessarily criticize everything. It's just that sometimes I call it specifically as a reviewer. Not to discuss the text, not to support the author, but to find what's broken.

And then I started formulating the task differently:

What's wrong with this text??

And the same Claude starts behaving a little differently. It talks less about what turned out well and more actively delves into weak spots.

But this immediately raises an unpleasant question.

If I myself told the model that something is wrong with the text, didn't I force it to just invent problems for me?

More remarks doesn't necessarily mean a higher quality check.

Let's remember this question.

I've been working a lot with such systems on Claude Code on my recent projects, and I've saved prompts, versions, and actual runs from them. By agent below, I mostly mean Claude Code subagent - a separate executor with its own instructions and context. Creating one such executor is simple. Problems arise when there are several of them and they have to complete a task to the end without you.

I Built a Very Smart Bureaucracy

The first approach seems obvious.

Let's create narrow specialists.

A researcher is responsible for facts. A strategist - for structure. A writer - for text. QA - for errors. A stylist - for presentation.

Each knows their job.

Only it quickly turns out that each agent can honestly say "I've done my part," and the final result can still be crappy.

We're not assembling all this for the sake of a beautiful list of agents. I don't want to go between ten sessions later and manually manage them as a dispatcher.

I want to set a task and get a result.
