We continue to experiment with 3D modeling. In today's experiment, we will recruit the talents of ChatGPT 5 to write ready-made scripts for Blender.

Blender Surprise

The Western internet is increasingly discussing a workflow whose essence is simple: LLMs, usually Claude Opus in this context, are connected to Blender using an MCP connector.

Briefly: MCP, or Model Context Protocol, acts as a special link that helps AI connect directly to external databases, websites, and third-party services. With MCP, AI can be given access to tools that we usually work with manually.

But today, for the sake of experiment purity, we will go the hardcore route and generate Python scripts, which we will then feed to Blender, to see how viable the result will be.

Game genre: medieval pseudo-fantasy in a low-poly style. Items were chosen randomly.

Prompts were written directly in Russian with a simple description of the asset, such as:

"Write a script for Blender. This is a 3D model of a wooden, Anglo-Saxon shield, studded with arrows on the front. This is a game asset. Style: retro low-poly graphics."

Conclusion: LLMs make sense to use in Blender for modeling rough, coarse blanks, which will inevitably require manual refinement anyway. Also, it's probably worth trying pipelines with other LLMs and seeing what output their prompts can produce.

For now, at least for static 3D models, generating initial references in Nano Banana Pro or Krea 2 followed by processing through models like Meshy works best.
