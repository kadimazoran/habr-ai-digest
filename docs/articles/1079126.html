Machine learning specialists from the University of Toronto have published a preprint of a scientific paper describing an "adaptive" computer worm that spreads through a corporate network by exploiting individual vulnerabilities of specific systems.

Traditional worms of the past, such as WannaCry, exploited pre-known vulnerabilities. Their spread could be stopped by patching these vulnerabilities. According to scientists, LLM agents create a fundamentally new threat – a worm that generates individual attack strategies for each new target. An external expert cannot predict how the worm will change and what vulnerabilities it will exploit in the future. Consequently, it is harder to stop its spread.

Scientists have developed such a worm and tested its operation in the isolated corporate network FakeCorp.

The worm maintains its infrastructure by running LLMs on infected machines. The distributed computing system searches for vulnerabilities and develops targeted attacks against new targets, using a list of known vulnerabilities. GPU resources on infected machines are used to compute attack vectors against a new target.

The system consists of two main components:

  1. A GPU LLM component running on compromised GPUs.

  2. An agent framework organized into three modules:

    1. Agent core (recursive reasoning based on observations);

    2. Memory module (context and information management);

    3. Tool module for interacting with target machines (console session management, file transfer, payload deployment, etc.).

Hierarchical memory records the specific current state, including the agent's current lifecycle phase (discovery, vulnerability exploitation, or replication), the active target machine, and the vulnerability hypothesis, the current task, command history, observations, failures, and counters to limit retries on the same machine.

The reasoning graph (in the illustration on the right) goes through key reasoning nodes that prompt the LLM to propose a plan, critique or refine that plan, select and execute an action, summarize the result, and make a decision: continue with the current hypothesis or refine it. Each node forms its query from phase-dependent memory slices and can update this memory using structured fields or free-form text.

The implementation details have been intentionally concealed by the scientists.

The program preys on the computing resources of infected machines, so the attacker's cost for each new infection is close to zero. This "creates a destabilizing economic asymmetry between attackers and defenders," the authors of the scientific paper believe.

Defense against such a threat is also non-trivial. The worm does not use commercial LLM platforms or third-party hosting, so its "command center" cannot be shut down.

The experiment showed that "self-sustaining LLM-based cyber threats" are quite real: "We must prepare for autonomous LLM adversaries: malicious software systems that spread without human intervention and are defined not by fixed exploit code, but by their ability to reason about goals, adapt to observations, and synthesize attack logic in real-time," the authors write in the conclusion of the scientific paper.

One can imagine the capabilities of such programs if the function of adaptation and LLM reasoning were added to the worms of the past: SQL Slammer, Conficker, or Stuxnet. Thanks to the new functionality – with autonomous agents and local LLMs on infected machines – the worm's spreading capabilities would significantly increase.

On the other hand, a malicious LLM agent would spread much slower than the fast worms of the past: it is iterative, noisy, and often makes mistakes. In its current form, it would be detected much more easily than those classic worms.
