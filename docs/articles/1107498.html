On November 12, the source code for Edge0 -145B and -120B was released. According to the developers, Edge0-145B is the world's first open model with this number of parameters that runs on a local device. The model's reasoning, code handling, and agent capabilities are compared to leading cloud models. We'll find out if this is true now. The model can already be tested on HuggingFace.

What Tasks Does the New Edge Solve

We all know that running large local models on our devices can sometimes be an impossible task. We lack the GPUs, which are becoming increasingly expensive. Edge0 developers assure that the peak memory requirement for the 145B model is 29 GB, and the decoding speed exceeds 80 tokens per second. The company does not specify a laptop model but targets devices with 48 GB of memory.


If medium-sized LLMs are implemented, they may prove inefficient for demanding tasks. The benchmarks of Edge0 with other models presented below might make users doubt this.

According to the developers, the model decomposes tasks, writes and executes code, debugs errors, and visually verifies results when working on projects like 3D modeling, game development, and PCB design.

Local operation with the model does not require token payments, and data can remain on your computer.

Benchmarks, Technical Information About the Model

Edge0-145B/120B has open weights, based on Qwen3.8-Flash-Next. The 145B model contains 145 billion parameters and 10 billion active parameters per token.

The expert pool is 84.6B, with 512 experts per layer; 10 experts and 1 general expert are activated per token.

The Q3_K build weighs 40.8 GB, and on an RTX 5090 gaming card costing 800,000 rubles, the speed is 120 tokens per second.

Inside Edge0-120B, as one might guess, are 120 billion parameters and 8.64 billion active parameters per token. The expert pool is 60.4B, with 512 experts per layer; 10 experts and 1 general expert are activated per token. The Q3_K build weighs 28 GB, and on an RTX5090, the speed is 145 tokens per second.

In benchmarks, Edge0-145B is compared with Chinese and American models.

In the DeepSWE 1.1 benchmark, which evaluates programming and engineering problem-solving, the model scored 64.6 points, surpassing Qwen3.8-Flash-Next with its 58.7. Terminal-Bench 2.1, which assesses terminal operation and task autonomy, saw the 145B model achieve 86.52 points compared to Claude-Opus-4.6's 78.2 points and Qwen3.8-Flash-Next's 83.3 points. In HLE, which evaluates the model's knowledge in complex sciences and reasoning, the 145B model scored 35.4 points against Claude-Opus-4.6's 40 points.

Here, Claude proved slightly more intelligent, but Edge0's statement is understandable – they can compete with Qwen. Comparing themselves to Claude Opus 4.6, released on February 5, 2026, is questionable: Anthropic already has Claude Opus 5.5.

Conclusions on Edge Models

Edge0-145B and 120B performed well in benchmarks. The developers' claims have been confirmed – the models are effective in handling complex tasks and long contexts. Now we await user feedback on the model. A significant drawback could be the license – the model is free for personal use and for deployment within a company, but commercial use of the model is only possible after signing an agreement with Edge0.
