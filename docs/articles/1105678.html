A thousand Claude Fable 5.2 agents formalized the proof of Fermat's Last Theorem in Lean in 30 hours. In a similar experiment, Opus 5.5 completed 26% of the formalization in the first 18 hours and made almost no progress in the remaining 12. Anthropic published both runs in the announcement of Fable 5.2 and Mythos 5.2.

What Lean Verified

Fermat's Last Theorem states that for an integer n > 2, the equation aⁿ + bⁿ = cⁿ has no solutions in positive integers. Andrew Wiles' proof was published in 1995 after a gap was corrected in collaboration with Richard Taylor. The agents' task was to write down the mathematical argument in a computer-verifiable language.

In Lean, a statement is defined by its type, and a proof is a term of that type. Tactics construct the proof term, and the kernel verifies its type. To apply a lemma, its premises must be proven. If the required lemma is not in the library, it must also be written and proven in Lean.

In the September experiment, Anthropic tracked these dependencies in Prove2Me. The platform stored a directed acyclic graph of statements. Through it, agents could see which lemmas were already proven and where work could continue in parallel. That run took 11 days, and the final proof included 29,500 intermediate theorems. A separate check confirmed that the final formulation matched the one in Mathlib. Description of the September experiment.

A Thousand Agents and One Run Per Model

In the new experiment, Fable 5.2 received short starting instructions and a list of intermediate statements to evaluate progress. According to Anthropic, the agents distributed the work themselves and did not use mathematical reference materials. Humans intervened rarely. Compared to the September experiment, the number of tokens spent on actions decreased threefold, and the formal proof text was seven times shorter.

For Opus 5.5, Anthropic used the same configuration with approximately a thousand agents. Both teams resumed work from a saved state after 18 hours. The graph in the announcement shows one run for each model. The September experiment used a different model and a different coordination scheme. Graph and experiment conditions.

Migration from Python to Rust and OS Prototype

Internally at Anthropic, an agent team on an early version of Fable 5.2 migrated a critical service from Python to Rust. According to Anthropic, the service's startup time decreased approximately 26-fold.

In another experiment, Fable 5.2 coordinated the work of over a thousand sub-agents on an operating system prototype for eight days. They started with an empty folder and obtained a system that boots on a laptop. It has a kernel, disk, keyboard, and network drivers, file storage, a windowing interface, and an installer.

On FrontierCode 2.0, Fable 5.2 achieved 49.1% at the Xhigh effort level, compared to 32.4% for Fable 5.1 with the same setup. On the same test, Fable 5.2 in High mode achieved roughly the same as Opus 5.5 in Max mode. Solving one task cost about half as much. Methodology and results table.

How Mythos Differs from Fable

Fable 5.2 and Mythos 5.2 share the same base model. Fable has additional restrictions on high-risk cybersecurity and biology tasks. Mythos is available to vetted organizations through Anthropic's programs for security and biomedical researchers.

In an internal CVE Rediscovery test, Mythos 5.2 found 89.6% of vulnerabilities, compared to 78.3% for Mythos 5.1 and 81.3% for Opus 5.5 with safety restrictions disabled. The October run involved 1829 already published CVEs. The models were given project versions before the fix to test how many known vulnerabilities they could find independently.

API, Speed, and Price

In the Claude Platform API, the model is available under the name claude-fable-5-2. Fable 5.2 is also available through AWS, Google Cloud, and Microsoft Azure. The base rate for both models is $8 per million input tokens and $40 per million output tokens. Anthropic states that compared to version 5.1, generation speed has increased by up to 30%. In Fast Mode, tokens are generated up to 2.5 times faster, with a rate of $16 per million input and $80 per million output tokens. Official Anthropic Announcement.
