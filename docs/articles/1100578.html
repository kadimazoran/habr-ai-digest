What the Hub Should Do

Looking at agent interaction from the user's perspective, there are few actions:

- The agent writes text;
- The agent calls a tool (a command, file edit, search);
- The agent requests permission to call a tool;
- The agent asks a question with answer options;
- The agent sends a file;
- The turn ends or fails with an error.

In the other direction, we receive user messages, responses to permissions and questions, files, and stop commands. All of this needs to be displayed in a Telegram thread and sent back to the agent. The problem is that each agent communicates this in its own language.
