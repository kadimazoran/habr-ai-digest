A couple of weeks ago, I came across a colorful visualization of someone's harness. I admired it for a few minutes and decided I wanted something similar for my own use case, but simpler.

I immediately turned to my agent based on Claude Code with a request to draw how it itself visualizes its workflow. It drew a map: the model in the center, ten stations around it — files, terminal, network, memory, sub-agents, hooks, and so on. I invoked the tool — an impulse runs to the station. Below the map is a list of recent calls.

I liked it. I decided to share.

And then it took off.

Ten Days in Numbers

The first version was released on November 9th. I wrote a post on r/ClaudeAI with a video.

  • On the night of November 11th — 100 stars

  • November 12th — 500

  • November 18th — 1000, on the tenth day

On November 11th, fourteen versions were released in a single day. People wrote in the comments what they were missing, and almost every request became a new version. They asked to flip the map so that "you" were at the bottom — done. Asked for custom colors — done. Transparent background — done. Someone sent a fix for Windows paths, then Italian captions, then Portuguese.

Now it's version 0.12.0.

What Was Added

Briefly, without order:

  • A ring around the center that shows how full the context is. It's praised in reviews more than anything else.

  • Route: a thin line between the last stations.

  • Background tasks remain on the map until they are completed.

  • Seven caption languages, with Italian and Portuguese contributed by users.

  • Scale buttons in VS Code, also contributed by users.

  • How many tokens each call added to the context.

What Was Tried, Abandoned, and Reconsidered

The main story here is the map in the terminal.

Claude Code's mod only allows drawing images within the application and VS Code. The terminal only showed text. On the second day after release, the first question came: where's the graphics?

I tried it myself. A map made of characters, ten stations in a circle:

                      ○ You 2
           Hooks 2 ✕           ○ Model 14
     Skills 1 ○                     ○ Memory 5
               ( CLAUDE · opus 5.5 )
       Agents ·                     ○ Files 9
           Browser ·           ● Shell 6
                    ○ Network 3

It turned out to be garbage. Seven lines of screen, no movement, and without movement, the map is pointless to look at. It didn't make it into the mod, remaining for a while as a separate branch for those who wanted something strange.

And then enthusiasts came with their own versions.

One submitted a pull request of 2000 lines: the mod itself draws the map in PNG and sends it to the terminal, frame by frame. It works in terminals that can display images. I asked for further development, and eventually it was accepted, released in 0.6.0.

Another created a Braille map for terminals without graphics, like Windows Terminal. That was also accepted.

Then the image managed to break and get fixed.

A few days after its release, someone wrote that they ran out of memory. We checked: iTerm2 grew from 286 MB to 17 GB in five minutes. The terminal stored every frame until the tab was closed. It was not possible to bypass this from the mod's side, and in 0.9.0, the image in iTerm2 was disabled.

I sent a report to the iTerm2 author. He fixed it the next day. In 0.12.0, the image was re-enabled, starting with iTerm2 3.7.8.

The second story is shorter. I decided to submit the mod to the Anthropic catalog. To pass automatic validation, I had to trim and add some things. The catalog did not accept mods with a hook for permission checks. In 0.4.0, the hook was removed, and with it, two lines on the map disappeared. In the end, after all checks and submitting the application, a rejection came: it turned out that this catalog only accepts mods from verified organizations and wouldn't take us anyway. In 0.5.0, the hook was restored.

The MP4 demo also went back and forth: it was removed from the repository, but links from outside pointed to it. It was put back.

What Was Rejected

Skins. They offered entire themes, steampunk and a night sky with comets. It looked beautiful. We didn't accept them: the map is needed to understand at a glance what the agent is doing, and with comets, it becomes mere decoration. Colors are customizable, so steampunk can be assembled without code.

Buttons on stations. They asked to be able to disable the network or terminal from the map. We refused immediately. The mod only observes and does not change anything, and all trust in it is based on this.

Layer for other agents. A pull request was submitted with an adapter for other hosts. We didn't accept it: no one ran the map in anything other than Claude Code, and we don't want to drag code for something that doesn't exist. The port is better off in a separate repository, and such repositories have already appeared.

The Choice

Requests pulled in two directions. We could have expanded into a universal mod with everything: switches, skins, other agents. Or remain a small visual add-on.

We remained small. On the fifth day, we formulated the main principles, there are six of them:

  1. The mod observes and does not change anything

  2. Captions only show the name, no content

  3. It costs almost nothing

  4. A failure on the map does not affect the work

  5. The map is calm

  6. It works out of the box, and what you have configured remains

Under each principle, it says which test protects it. For the first, there's a test that the event passes through exactly as it arrived. For the third, there are measurements with a time budget. Plus, the repository contains a list of everything the mod requests from Claude Code, and each pull request checks against it. Network, file reading, and process execution are not in this list.

There are also five questions that weigh any new idea. The first of them: does this require changing the event or refusing it? If yes, it's not for this mod.

The second principle was needed before it was written down. The mod receives the entire agent call: command line, paths, addresses with parameters. And the panel on the screen, the screen gets into screenshots. Therefore, from the command curl with a token in the header, only the word curl remains on the map; from the address, only the host. On the third day, a code reader found a way to record the address so that the password from it still ended up in the caption. It was fixed the same day.

Reviews

Since publication, several reviews have appeared in various specialized blogs.

In Japan, a video was made with a test: five tasks, forty calls, checking against the map every half second. All forty landed on the correct station. The target name appeared in thirty out of forty, and the output there is honest: the map provides an overview, but it doesn't replace the log.

In China, on CSDN, at least six articles have been published, one of them entirely about how the animation in SVG is implemented. The repository there has gained a mirror.

In Spain, the mod was run through a security scanner and ten of its triggers were manually analyzed. All ten turned out to be false positives: the scanner flagged words like curl and sudo in tests and comments.

What Others Made From It

Two took the code further. One created an overlay for Codex using the same drawing files. The second built their own panel and added what I don't have: a feed showing where the time of the move went. Both credited the source.

Conclusion

The mod is very simple, it does nothing, it just shows the current activity. Apparently, my agent turned out to be a genius, for such a thing to take off and be liked by people.
