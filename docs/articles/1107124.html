In recent years, Microsoft has been integrating artificial intelligence features into its Bing search engine, including AI-generated answers. The company now offers two ways to disable AI answers in the search engine.

Microsoft has acknowledged that, according to its research, users want to decide for themselves whether AI should participate in the search process. Some prefer concise summaries generated by neural networks, while others prefer to browse results independently, compare sources, and draw their own conclusions. To accommodate these preferences, Microsoft has released the Microsoft Bing AI Search Choice browser extension. It is currently available in a preview version for Google Chrome and Microsoft Edge. After installation, the extension adds a simple toggle switch that allows users to enable or disable AI answers in Bing. The setting is saved for all search queries, so users don't have to change it every time.

However, installing the extension also makes Bing the default search engine in the browser. This is an unnecessary requirement for those who only want to manage AI features in Bing without changing their general browser settings.

It is noted that Microsoft could have simply added a corresponding toggle switch to Bing's settings, allowing users to permanently disable AI answers without installing additional software. Such a switch could even have been placed directly on the search results page.

The company also offers another option that does not require installing an extension: users can add the operator "-ai" to their search queries to receive traditional results without AI involvement. For example, when searching for "best laptops 2026 -ai," neural network answers will not be displayed. However, this operator must be entered with every search, which is not very convenient.

In the summer, Microsoft introduced the Web IQ set of APIs based on the Bing search engine. It is positioned as a search engine for AI agents, offering them structured data to work with. Web IQ operates on the global Bing index, giving it access to billions of documents across over 100 languages and markets. However, to perform semantic search instead of simple keyword matching, the system projects information into a vector space using an open-source embedding model from Microsoft. To improve speed, it extends DiskANN, allowing it to process large indexes stored on disk without needing to load them all into memory.
