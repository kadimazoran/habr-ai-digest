Hello everyone! This is Sergey Fomin, Product Manager at Habr. We've expanded the SourceCraft feature on Habr – now the AI assistant SourceCraft Code Assistant not only helps you understand code in an article but also quickly grasp the material itself, see the main points from comments, or find practical applications.

The integration with the SourceCraft development platform, which we launched in 2025, helped understand code directly within the article. The feature appeared directly in code snippets: click the button, and the AI assistant explains what's happening in a specific code fragment, considering the article's context. During its operation, it has been used by over 645,000 users, and the total number of clicks on the "Explain Code" button has exceeded one million.

Robert Aksenov

Product Director at Yandex SourceCraft

Habr readers turned out to be the right audience for SourceCraft – qualified and working with code. Plus, the response to the launch of "Explain Code with SourceCraft" was useful for us and helped us come up with improvements and next steps.

But code is not the only thing you have to deal with when reading a technical article. Sometimes the material itself spans several screens, and you don't have time to read it entirely right now. Or the article is already clear, but you want to quickly see what has been written about it in the comments. And sometimes, after reading, another question arises: okay, where can this be applied?

Therefore, we have expanded the feature's capabilities – now, instead of one "Explain Code" button, there are four more options available:

  • create a summary of the article,

  • compile a summary of comments,

  • explain in simple terms,

  • suggest practical applications for the material.

We chose the new scenarios after a small study of Habr users.

How it works

All new scenarios are available via a button to the right of the article title. The user selects the desired action, after which Habr transfers the necessary context to the AI.

For each scenario, Habr transfers a different set of data. If you need to explain code, it's the article and a specific snippet. If you need to summarize comments, the comments on the publication are sent in the request.

The principle here is the same as in the first version of the feature: Habr determines what data is needed for a specific scenario and transfers it to SourceCraft.

The response generation itself happens on the AI assistant's side.

The user doesn't have to copy the article, comments, or code into a separate chat: select the desired scenario, and get the result within the context of the same publication.

What Each Scenario Does

Article Summary. If the article is long and you don't have time to read it now, you can start with a summary. The AI extracts the main points of the material and explains the essence of the article in a few sentences, as well as collects key ideas. This is useful, for example, to quickly understand if it's worth reading the article in full, or to refresh the content of an already familiar publication.

Arseniy Zhizhelev

Developer at Yandex SourceCraft

Currently, the model receives a specially prepared prompt and the textual content of the article, which works quite well if the images only illustrate individual points discussed in detail in the article. In the future, we plan to use a multimodal model for image understanding. This will also allow us to consider technically rich diagrams that contain details not reflected in the text.

Explain in Simple Terms. Sometimes the problem is not the length of the article, but the fact that the author uses a lot of technical terms and assumes a certain level of reader knowledge. In such cases, you can ask the AI to explain without needing to understand the material and terms yourself. The assistant will break down the article step by step without technical jargon.

This scenario can be useful, for example, for specialists from related fields or for those who are superficially familiar with the topic but want to quickly understand a specific part of the article.

Comment Summary. For a good article on Habr, the discussion sometimes turns out to be no less informative than the publication itself. But if there are many comments, scrolling through the entire discussion can be a task in itself. Now you can ask the AI to compile the main points from the comments.

The assistant will analyze what users are saying, tell you how many comments were included in the analysis, and provide examples of the most interesting and relevant comments.

Arseniy Zhizhelev

Developer at Yandex SourceCraft

In the comments to an article, an interesting discussion often unfolds that goes far beyond the article itself. The model's task is to extract either new ideas that develop the article's thought or original opinions from authors criticizing the article. The model receives both a summary of the article and the comments themselves, linked in a tree-like discussion structure. This allows the model to trace chains in a unified context.

I would like to point out that this is a summary of an existing discussion. The AI does not write comments on behalf of readers or add new content to the discussion.

How to Apply in Practice. There is also a more practical scenario: after reading an article, you want to understand where the acquired knowledge can be used.

In this case, the AI suggests practical applications for the material – based on the content of the article itself.

Studied the idea – saw where it can be used

In addition to the summary, the assistant will offer advice – how to best apply the information from the article in practice and what to consider.

Here, the answer is no longer a retelling of the article: the scenario's task is to help transition from what has been read to possible practical applications.

Explain Code. And the familiar scenario is still here.

If there is code in the article, you can still click "Explain Code with SourceCraft" and get an explanation of the selected fragment, considering the article's context.

The AI can make mistakes – if you notice any inaccuracies or errors, please contact us via technical support.

What's Next

The first version of "Explain Code" has already gained its audience. Now we want to see which of the new scenarios will be most useful in real Habr reading. It will be particularly interesting to compare their usage: it's obvious that not every article needs a summary, and a comment summary only makes sense where there is something to summarize.

Robert Aksenov

Product Director at Yandex SourceCraft

Previously, we would first read the material in its entirety and then form an understanding from it. Now, more and more often, we first ask the AI: "What is important for me here?" – and then we go read only the relevant parts of the original.

This approach significantly simplifies entry into complex technical materials. But there is a downside. Previously, the author of the article set the logic and order of argumentation; now, the AI increasingly does this.

Research confirms: people grasp the main conclusions and high-level ideas well, but the methodology, details, and how the author arrived at these conclusions begin to get lost.

Therefore, going forward, we will look not only at the number of clicks but also at which scenarios are truly adopted by readers. In the meantime, try the new version of the feature on Habr articles and tell us in the comments which scenario you found useful and which ones are missing.
