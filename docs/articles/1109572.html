The open-source project rust-anything has been published on GitHub, which helps rewrite games and applications from various programming languages (TypeScript/JavaScript, Python, Go, Ruby, Java, PHP, and C# currently in preview) into Rust. The solution works in conjunction with Claude Code, Codex, and other AI agents. The neural network rewrites code into Rust piece by piece, and the project's toolkit ensures that nothing breaks during this process.

"Rewrite your entire application in Rust — module by module. rust-anything records the behavior of your current application in Node.js (TypeScript/JavaScript), Python, C, Go, Ruby, or Java, and then verifies each Rust-rewritten part against this record before moving on — until the entire application is pure Rust. CLI, HTTP servers, and libraries are supported; your AI agent (or you yourself) writes the Rust code," explained the solution's authors.

In separate tests, the authors claim up to a 20-fold speed increase for rewritten solutions in Rust.
