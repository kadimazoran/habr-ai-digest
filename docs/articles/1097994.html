You launch three agents at once. One is done. The second has been waiting for your 'yes' for ten minutes. The third crashed, and you don't know about it. You only find out when you switch windows one by one.

We created Lumio to stop working like this. It's a free Mac app that turns your MacBook notch into a remote for AI agents. In version 1.2, Cursor and GitHub Copilot in VS Code have been added to Claude Code and Codex. Now all four are visible in one place, and you can respond to almost anything without opening the editor.

One glance instead of ten windows

Hover over the notch, and it will expand into a list of sessions. Each one shows what the agent is currently doing in plain language: 'writing code', 'running command', 'searching the internet'. Next to it is the plan progress ('3 of 7') and a memory bar: it will tell you when it's time to start a new session.

No notch or working on an external monitor? Lumio will draw a virtual one below the menu bar.

Agent is waiting — the notch is calling

When an agent needs your permission or asks a question, the notch starts to softly glow with its color, and a dot appears in the menu bar. No need to stare at the window: you'll notice it out of the corner of your eye.

You can respond directly in the notch:

  • Allow or deny a command — click the notch and press Enter;

  • Choose an option from the agent's question — by number on the keyboard, or type your answer;

  • Respond with text — Codex will receive the answer immediately, Claude Code with auto-send enabled.

Permissions work for all four agents, multiple-choice questions work for Claude Code, Codex, and Copilot. Lumio only asks what the agent would ask itself: it respects your lists of allowed commands and 'allow all' modes. If Lumio is closed or you don't respond within two minutes, the question returns to the editor as usual. The agent will never get stuck because of us.

'Done' — with the main points

When an agent finishes, a card pops up. The main point of its response is the title, followed by changed files: each opens in VS Code with a single click. It also shows the branch and the number of lines changed. You don't need to read a wall of text in the chat to understand what happened.

Pixel Office

Double-tap the right ⌘, and a pixel office grows from the notch. Each session here is a person at their desk. Those working are typing at iMacs, and their screens show what they're doing: code, terminal, or browser. The one waiting for you is standing up from their desk. Those who have finished go for coffee and chat on the couch about their current tasks. If an agent has launched assistants, they stand behind them.

On the wall, there's a scoreboard: how many tasks were completed today, Claude and Codex limits. Light follows the real sun: it gets lighter in the morning, lamps turn on at night, and faces are illuminated by screens. Every pixel is drawn with code, even the quiet lo-fi music in the office is written with code.

The office is not just decoration. Leave the window open on the side and see your entire team at once: who is working, who is waiting, who has been silent for a long time.

While you're away

  • Mac won't sleep while agents are working. The screen can go dark, sessions will continue. You go for lunch, come back, and everything is ready.

  • Daily summary. Optionally, Lumio keeps a daily log: what was done, what was fixed, and what's next for each project. It writes to Obsidian, Apple Notes, or a regular folder, with a new entry each day.

Little things that make you not want to turn it off

  • A thought? Right ⌥. Press it, type, Enter — the note is saved to Obsidian, Apple Notes, or a folder. Two seconds, no window switching.

  • Music. What's playing in any player or browser tab, with track switching right in the notch. Colors from the album art breathe around the notch.

A bit from the inside

The four agents are structured very differently. We made the main decision back with Codex: inside Lumio, there's a single event language. Everything coming from the agents is first translated into it. That's why the list, cards, and office don't know who they're working with, only differing by color and icon. A new agent for us is a new 'translator', not a new application.

Agents have different capabilities. Claude Code and Copilot have hooks that can both allow and deny commands. Cursor's hook can only deny: it can't press Run for you, and we had to find another way (and we did). Codex has no hooks for permissions at all. We handled each such case separately, but for the user, it all looks the same: a card in the notch and Enter.

Three rules we keep for all agents:

  1. Do not delay the agent if the user is not needed.

  2. Ask only what the agent would ask itself.

  3. If Lumio is closed or frozen, silently step aside.

The agent icons are also drawn with code, pixel by pixel: ready-made logos 11 pixels high turn into soap.

Light and quiet

At rest, Lumio uses less than 1% of the processor. Constant animations run through Core Animation, and the office is drawn only while its window is open. Lumio doesn't need screen recording. Universal Access is only needed if you enable auto-sending responses to Claude Code yourself.

Your code stays on your Mac

No accounts or tracking. Lumio reads the local files of your agents. It only sends an update check once a day: a random Mac ID and the names of the agents you've used in the week (e.g., 'claude,codex'), and nothing about your files or projects. The check can be turned off. Lumio gets the latest Claude limit through your Claude Code. Daily AI summaries are off by default. If you enable them, short task summaries are sent through your Claude Code or Codex.

Try it

The core of Lumio is free forever. Requires macOS 14 or newer, Apple silicon or Intel, and at least one agent: Claude Code, Codex, Cursor, or GitHub Copilot in VS Code.

The easiest way to install is with a single command in Terminal: without macOS warnings, Lumio updates itself afterward.

curl -fsSL https://lumiomac.com/install.sh | sh

Or download from the website: https://lumiomac.com
