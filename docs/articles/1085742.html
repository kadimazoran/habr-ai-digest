Sometimes LLMs get confused about the language they respond in (Why neural networks think so). So why not help them forget the languages we're not interested in.

As we know, LLMs work with tokens: they translate chunks of words into multidimensional vectors, multiply them by their weights many times, add them together, and then, based on the last vector that has absorbed all the context, they compute the next token. Consequently, it shouldn't be difficult to prohibit the computation of specific tokens from languages we don't need.

Let's try to dissect a small model, Qwen3.5-0.8B-Q8_0.gguf, and modify it.

import gguf

reader = gguf.GGUFReader("./Qwen3.5-0.8B-Q8_0.gguf")
tokens = reader.fields.get("tokenizer.ggml.tokens").contents()
print(f"Total tokens {len(tokens)}")
types = reader.fields.get("tokenizer.ggml.token_type").contents()
print(f"Total token types {len(set(types))} : {set(types)}")

# Total tokens 248320
# Total token types 4 : {1, 3, 4, 5}

It uses a byte-pair encoding tokenizer with a vocabulary of 248320 tokens, divided into 4 types (1 - text, 3 - <|special|><|tokens|>, 4 - <special></tokens>, 5 - padding). Text tokens range from id_0=! to id_248043=ありますか. Let's define a list of tokens we want to keep:

import sys

keep_check = regex.compile(r"["
  r"[\p{N}\p{P}\p{S}&&[\p{Script=Common}]]" # Numbers, punctuation, and symbols
  r"\s"                                   # Whitespace characters
  r"а-яА-ЯёЁ"                             # Cyrillic
  r"a-zA-Z"                               # Latin alphabet
r"]", regex.V1)

symbols_to_keep = set()
for cp in range(sys.maxunicode + 1):
  if keep_check.fullmatch(chr(cp)):
    symbols_to_keep.add(chr(cp))
print(f"{len(symbols_to_keep)} symbols")

# 7994 symbols

This gives us a list of 7994 symbols. Now we can filter the LLM's tokens so that they only contain these symbols.

from gguf.vocab import bytes_to_unicode

byte_decoder = {ch: b for b, ch in bytes_to_unicode().items()}
tokens_to_rm = set()
for i, t in enumerate(tokens):
  if types[i] != 1:
    # We are only interested in text tokens
    continue

  raw = bytes(byte_decoder[ch] for ch in t)
  try:
    text = raw.decode("utf-8")
    if not all((ch in symbols_to_keep) for ch in text):
      tokens_to_rm.add(i)
  except UnicodeDecodeError:
    # Leftovers of utf-8, let them be
    continue

  print(f"Remove {len(tokens_to_rm)} tokens")
  
  # Remove 100468 tokens

In total, out of the initial 248320 tokens, we will remove 100468. We will do this by zeroing out the weights in the penultimate layer, which is responsible for decoding the multidimensional vector into token logits.

for t in reader.tensors:
  print(t.name)

# output_norm.weight
# token_embd.weight
# blk.0.attn_gate.weight
# ... 329 more layers
# blk.24.nextn.shared_head_norm.weight
# blk.24.post_attention_norm.weight

This token_embd.weight is what we need. It's a shared encode/decode layer, so zeroing out tokens will also affect the LLM's ability to read texts in these languages. Well, that's a sacrifice I'm willing to make.

import numpy as np

token_embd = next(t for t in reader.tensors if t.name == "token_embd.weight")
n_vocab, bytes_per_row = token_embd.data.shape
block_size = 1*2 + 32*1 # Q8_0: one fp16 scale coefficient + 32 int8
n_blocks = bytes_per_row // block_size

# we will patch the file directly
token_embd_data = np.memmap(
  gguf_file,
  dtype=np.uint8,
  mode="r+",
  offset=token_embd.data_offset,
  shape=(n_vocab, n_blocks, block_size)
)
# zero out the fp16 scale coefficient
token_embd_data[tokens_to_rm, :, 0:2] = 0
token_embd_data.flush()
del token_embd_data
