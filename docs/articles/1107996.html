Cloudflare has open-sourced Kitesurf, an experimental browser engine for AI agents. Developers can now modify the code, run the engine locally, and use it in their own cloud systems. The project was introduced in August 2026.

Kitesurf loads web pages, parses HTML, applies CSS, executes JavaScript, and creates screenshots. AI agents can use it to interact with websites. For example, they can navigate pages, extract content, and fill out forms. Cloudflare notes that, thanks to its architecture, the engine reduces costs for such tasks, and uses less memory and CPU time compared to Chromium.

The project is based on modules written in Rust, recompiled into WebAssembly: Blitz handles HTML and structure, Stylo from Firefox handles CSS processing, and Linebender libraries handle text and 2D graphics. A separate engine, Boa, is used for JavaScript. It runs within WebAssembly.

For control, you can use the Chrome DevTools Protocol (CDP), and connect AI agents via MCP. At the end of summer, the Cloudflare team also added support for WebMCP. On websites that support this technology, agents can directly call described functions instead of sequentially clicking through the page.

In performance tests, Kitesurf saves memory and CPU time but is slower. For example, for creating screenshots, the CPU time and memory usage were 352 ms and 58 MiB, respectively, with an execution time of 1.51 seconds. For Chromium, the results were 1880 ms, 399 MiB, and 1.21 seconds, respectively.

Kitesurf's compatibility with the modern web is not yet complete. For instance, the engine is not suitable for video playback, WebGL, or long authenticated sessions. Rendering may also differ from Chromium.

Kitesurf's code is available on GitHub, and documentation has been published on the project website.
