A user discovered that Chrome's built-in AI assistant, Gemini, can silently consume RAM even when the browser itself is closed.

They noticed that after closing Chrome, several browser processes continued to appear in Windows Task Manager. These processes occupied between 300 and 700 MB of RAM, despite the option "Continue running background apps when Google Chrome is closed" being disabled. The user tried numerous solutions: disabling extensions, removing web apps, clearing cache and cookies, resetting Chrome settings, and disabling hardware acceleration, preloading pages, and on-device AI features. However, none of these helped.

Interestingly, when a new Chrome profile was created without logging into an account, the browser completely unloaded from memory after closing. This helped pinpoint the true cause: a subtle Gemini setting that most users are likely unaware of.

This setting allows Gemini to remain accessible even when the Chrome window is minimized or closed. To enable this, the browser keeps an active background process running in the system. Therefore, to completely shut down Chrome, this feature needs to be disabled, which in turn will reduce RAM consumption.

To check if such a setting is active on your system, navigate to chrome://settings/ai/gemini in Chrome or go to Settings > AI innovations > Gemini. In the "Preferences" section, find and disable the option "Show Gemini in Chrome in system tray and turn on keyboard shortcut." Google's own documentation also mentions this feature, explaining that when Gemini is activated in the Windows system tray, a corresponding icon appears, and keyboard shortcuts can be used to access the service.

However, as reported by Neowin, finding this description in current versions of the help article has become more difficult. Google now appears to be using AI to generate content, redirecting users to the Gemini chatbot for answers.
