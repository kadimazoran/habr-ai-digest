Web search is enabled unless it's disabled

According to Microsoft's documentation, web search is available to users even if no policy has been configured: "If the IT admin doesn’t configure the Allow web search in Copilot policy, web search will be available to users in both Microsoft Copilot and Microsoft Copilot Chat, unless the IT admin has set the Allow the use of additional optional connected experiences in Office policy to Disabled." The condition at the end is crucial: web search can be disabled by one of two policies. The user toggle is also related: "If the IT admin enables web search, the Web content toggle is turned on by default."

The "Allow web search in Copilot" policy is available, according to the page's wording, only in the Cloud Policy service for Microsoft 365. There are three modes: "Enabled in Microsoft Copilot and Microsoft Copilot Chat"; "Disabled in Microsoft Copilot and Microsoft Copilot Chat"; "Disabled in Microsoft Copilot Work mode; Enabled in Microsoft Copilot Web mode and Microsoft Copilot Chat". The third mode has a specific consequence: "web search in Researcher and Cowork in Microsoft Copilot will be disabled."

The documentation refers to the user toggle by two names. In the management section, it is "Web content", and in the interface instructions on the same page, it is "Expand Advanced, and turn off the Web search toggle".
