Meshy + Seedream = Dream Team?

If Seedream's descriptions are to be believed, it's a powerful model equipped with cross-modal attention between text tokens, visual patches, and reference embeddings, along with accelerated DiT inference.

All of this helps it maintain scene structure, logical consistency between frames during multi-frame generation, and analyze prompts, even complex ones, faster and better.

Let's try to create 10 low-poly 2D assets, see how consistent the results are, and how well they translate into 3D. The setting is still medieval-ish fantasy.
