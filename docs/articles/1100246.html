We are students from the AI Services and Platforms workshop at the Higher School of Economics' Engineering and Mathematics School and VK: Pavel Alekseev, Alexander Rozhkin, Andrey Argatkin, Alexey Pavlov, and Matvey Kamenev. In this project, we investigated how to improve the quality of models with linear attention to the level of ordinary transformers. Such a mechanism allows processing long sequences without a quadratic increase in computational costs, making it promising for more economical training of language models and processing long documents. During autoregressive text generation, it helps save memory: instead of a growing KV-cache, a fixed-size state can be stored.

The starting point was the Dense Attention architecture. It uses simple matrix operations without softmax but shows high quality in published experiments. Our supervisor, Andrey Argatkin, set a new research direction in the article on Dense Attention. We will explore which model components provide this result and whether they can be transferred to other attention variants.

The working hypothesis is that linear models lag in quality not only due to the replacement of softmax but also due to architectural settings and training. The number of heads, positional encoding, and layer scheme chosen for standard transformers are not necessarily optimal for a linear mechanism. We tested whether changing these components and MLM pre-training would reduce the quality gap without reverting to global softmax attention.

Motivation

Transformers have become one of the main architectures for sequence modeling in deep learning. Their success is due to the self-attention mechanism, which allows capturing global dependencies between elements of input data. However, standard attention has quadratic computational complexity with respect to the sequence length . This significantly increases the cost of training and applying models when working with long contexts.

Architectures with linear attention (Linear Attention) can help overcome this limitation. They approximate softmax attention or replace it with an alternative similarity function. This allows changing the order of computations and reducing complexity to with fixed feature and value dimensions. However, despite all computational advantages, linear models often lag behind classical transformers in quality, especially in tasks requiring modeling complex dependencies between distant elements of a sequence.

We aimed to improve the quality of linear models on Long Range Arena (LRA) tasks to the level of transformer models with quadratic attention complexity or surpass them while maintaining linear computational complexity with respect to sequence length. In this article, we examine experiments on Pathfinder32. We tested positional encoding, the number of attention heads, alternating local and global layers, MLM pre-training, as well as hybrid and polynomial attention.

Why We Chose Bidirectional Attention

The linear attention mechanisms discussed support both bidirectional and causal modes. We investigated the bidirectional mode, where the representation of each token is built considering the full context. This is natural for tasks where the input sequence is known entirely: classification, feature extraction, and masked element reconstruction. For autoregressive generation, a causal constraint is introduced: each token only considers the current and previous positions. Thus, one attention mechanism is suitable for both encoder models and autoregressive generation models.

In unidirectional recurrent architectures, to achieve bidirectional processing, the computational scheme needs to be modified. Typically, representations obtained from forward and backward passes are combined, as seen in Vision Mamba.

What We Tested

This computational scheme explains the advantages of linear attention, but it does not guarantee high quality on its own. In bidirectional mode, global attention gives each token access to the entire input. However, the model still needs to consider the token order and identify useful connections between them. Therefore, in our experiments, we tested not only the similarity function but also positional encoding, layer structure, and training method.

Positional Information

If queries and keys do not contain positional information, the function compares token features without considering their positions. Thus, one of the first questions is how to provide the model with positional information. In the baseline Dense Attention search, we compared three approaches: fixed sinusoidal encoding, learnable positional embeddings, and Rotary Position Embedding, or RoPE.

Unlike additive positional encoding, RoPE rotates queries and keys such that the positional part of their dot product depends on the difference in token indices. A non-linear feature map can alter this dependency. Therefore, for the Linear Transformer, we also tested how the order of applying RoPE and the feature map affects quality.

Local and Global Context

Positional encoding informs the model about token positions but does not limit their interaction scope. Global attention connects any positions, while a local layer processes only tokens within a single window. We used the Local-LocalShifted-Global scheme as a basis, which Andrey Argatkin described in the article on Dense Attention.

Here, local, shifted local, and global layers alternate. This allows separate processing of the immediate neighborhood and information exchange between distant parts of the sequence. We tested whether this scheme improves quality compared to a model using only global layers.

In this context, local windows are primarily for processing local dependencies, not for altering the already linear asymptotics. Additionally, we tested whether replacing linear attention within windows with softmax would improve quality. This led to a hybrid configuration: global layers retained Dense Attention, while local layers used softmax for processing the immediate neighborhood.

Number of Heads and Pre-training

Besides the token interaction scope, we varied the number of attention heads. With a fixed hidden size, this also changes the dimensionality of each head. For a hidden size of 128, eight heads operate with vectors of dimension 16, while one uses all 128 components. Multiple heads allow computing different similarity scores, and one wide head uses more features in each score. Therefore, we compared both options, not assuming that increasing the number of heads would necessarily improve the result.

We got the idea to test pre-training from the paper Never Train from Scratch. There, pre-training improved model quality on LRA and reduced the gap between transformers and SSMs. Unlike single-label classification for the entire sequence, Masked Language Modeling (MLM) trains the model to reconstruct masked elements from context on both sides. We tested whether this would help form useful representations for classification in the chosen one-head and eight-head Dense configurations and whether the ratio between their results would be preserved after pre-training.

Similarity Function and Normalization

Another question concerned the choice of the similarity function itself. In the SymPower series, we considered the polynomial kernel from the paper Symmetric Power Transformers. In it, the dot product of queries and keys is raised to the power of . The higher the power, the greater the difference between large and small magnitude scores. This can help the model highlight individual interactions without softmax.

The scale of the result changes simultaneously, so we considered the kernel power along with scaling and attention output normalization. We were interested in which combinations of these settings yield high quality when training from scratch, without MLM.

Task and Experimental Conditions

We used Pathfinder32 from the Long Range Arena benchmark. The task is to determine whether two marked points belong to the same path on a 32x32 pixel image. The model receives a one-dimensional sequence of 1,024 pixel values without an explicitly defined two-dimensional structure. The task requires considering both local line continuation and connections between distant segments. The quality metric is accuracy; the random guessing level is 50%.

The next question is: what quality can Dense Attention achieve if its number of parameters is comparable to our six-layer transformer implementation? With the same number of layers, hidden size, and FFN size, a BERT based on Dense Attention has fewer parameters. Its attention blocks lack separate learnable key and value projections, as well as an output projection. Therefore, the nine-layer Dense Attention has 1.36 million parameters, while our transformer has 1.24 million. Simultaneously, we changed the normalizations. Standard LayerNorm was used at the embedding level, at the model output, and before and after attention in global and local layers. Next, we tested what replacing the attention kernel itself would yield. In the polynomial mechanism based on Symmetric Power Transformers, hereafter SymPower, similarity is defined by the power of the dot product of queries and keys:

Increasing p amplifies the relative differences between large and small magnitude scores. For odd powers, the sign is preserved. Results

Experiments on Pathfinder32 confirmed our main hypothesis: the quality of linear models depends not only on replacing softmax but also on the consistent choice of architecture and training.

  • RoPE proved to be the best positional encoding for Dense Attention in the baseline search. However, direct transfer to Linear Transformer did not work. Rotation after the feature map and disabling the denominator improved results, but only for eight-head models.

  • Local and global layers improved Dense Attention with RoPE but reduced the quality of the transformer with RoPE. The best Dense configuration became a hybrid with global linear and local softmax attention.

  • MLM and number of heads. Pre-training improved both tested Dense configurations with RoPE and local layers: before MLM, eight heads performed better; after it, one head did. There was no universal advantage for any specific number of heads.

  • SymPower. The cubic kernel outperformed the quadratic one in all tested setting combinations, and output normalization further increased quality. The independent benefit of `d_scale` was not confirmed: scaling only helped when combined with `post_norm`. We achieved the best result without MLM.
