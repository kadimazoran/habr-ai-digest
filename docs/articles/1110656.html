It all started with my dissatisfaction: why do all Mac cleaners charge such a price? At the same time, the interface leaves much to be desired, and the program itself is overloaded with hundreds of functions (it cleans Macs, serves as an antivirus, and can do almost anything else).

First thought: we live in the age of AI automation, I can create such software for free. But how to understand what exactly to delete?

Simple idea: have Claude sequentially install over 900 popular applications on a "clean" macOS virtual machine (several versions). Then, during use, analyze what junk these programs leave behind. Then check everything. Check again. And again. Only add to the database what is actually confirmed as junk. After all, losing something important is extremely critical.

I made the program for myself and didn't plan to release it, if not for one big BUT: I didn't expect such results, and even more so I didn't expect them to significantly surpass what's available on the market.

Therefore, meet: MacWashing. Completely free and Open Source. Works without network access.
