The user attached a skill to the AI agent and wrote a work note. The skill was supposed to add a comment to a report in a corporate project management system. However, the model didn't even call the tool.

The tool's description had a condition: use it only when the user explicitly asks to add a comment to the system. The person had already selected the skill and started writing the note, but for the model, this was not enough.

I am developing IskraBot, a Russian AI agent. I recently created a skill for a designer's corporate system and fixed a VPN connection to 1C in another integration. I will discuss the problems I encountered, but first, let's talk about what a skill is.

What We Call a Skill

IskraBot has text-based and programmatic skills. A text-based skill provides instructions for the model: what to clarify with the user, in what order to perform the task, and how to format the result. For example, the 'Presentations' skill describes the process of preparing slides and checking a finished presentation.

A programmatic skill contains code for specific operations. With these skills, IskraBot can find a document on Google Drive, show the latest emails in Gmail, or retrieve deal information from amoCRM or Bitrix24. Integrations with 1C and the UniSender mailing service also fall into this category.

The model selects the appropriate action and processes the request. The programmatic part makes the call, and the platform handles the connection, permissions, and user interaction.
