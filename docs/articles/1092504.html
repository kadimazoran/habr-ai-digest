I wanted to develop my own AI processor, found openTPU, bought an FPGA for ~$50 with 4GB of RAM, connected it to a regular mini-PC, and ran a large language model on it — and flew into space (in a positive, dopamine-fueled sense).

No NVIDIA. No graphics card. On an open architecture developed with the active participation of AI agents.

openTPU is an open AI accelerator by Felipe Sens Bonetto.

I became curious: is it really possible to take such a project from GitHub, load it onto a physical FPGA, and run actual LLM inference?

According to the project author's measurements on the same board:
→ Qwen3-0.6B — 31 tokens per second
→ Qwen3.5-2B — 12 tokens per second
→ LFM2.5-230M — 86 tokens per second
→ Qwen3.5-35B — a 35 billion parameter model on a card with 4GB of memory, 4 tokens per second

And all this on an FPGA that is far from new.

🔧 What I did:

→ Bought a Xilinx Kintex-7 XC7K480T with 4GB of RAM on AliExpress (board information: 1 and 2)
→ Connected the FPGA to MINISFORUM via PCIe
→ Built the firmware (bitstream) in Vivado
→ Configured drivers and PCIe DMA
→ Prepared the software environment
→ Loaded real neural network weights
→ Launched inference, including Qwen

And it all worked!

💡 Why is this more interesting than just running another neural network?

Usually, we perceive GPUs as a ready-made platform: we buy a graphics card, install CUDA, and run models.

But what if we go in the opposite direction?

Instead of choosing hardware for a neural network, we create our own hardware for specific neural network computations.

This is precisely why specialized AI accelerators are developed, including TPUs — processors optimized for machine learning operations.

Of course, the current board is not yet a competitor to the NVIDIA H100. And a working prototype is still far from a mass-produced ASIC.

But now, we can not only discuss our own AI processor architecture but also experiment with it on physical hardware.

🔬 What I'm thinking about next:

We are already using AI to write programs. Now AI is designing the processors it will run on. Previously, having your own AI accelerator was a task for Google and NVIDIA — today, a prototype can be assembled and tested by a single engineer.
