What is Auto-editing in Claude

This feature is not available in the regular Claude chat. Auto-editing can be done through Claude Code — a version of Claude that runs on your computer and can perform actions itself: open files, launch programs, create new files. Claude Code was initially created for working with code: writing and debugging programs. But as it turns out, it can act on anything, including video.

Claude Code can edit using a free add-on (skill) called video-use from the open-source browser-use team. A skill is a set of instructions and programs that explains to the agent how to perform a specific task. Install the skill, and Claude Code knows how to edit.

The project appeared on GitHub in the spring of 2026, is distributed under the free MIT license, and works with Claude Code, OpenAI's Codex, and other similar agents. Why is everyone talking only about "auto-editing in Claude" then? The project was primarily developed and demonstrated for Claude Code, and the installation instructions are written for it. For Codex and other agents, the skill is connected differently; the path is described in their documentation.

The quality of the results depends on the agent chosen: how accurately the model understands the task, follows your description, and doesn't get lost in a long transcript. There are no comparative tests of Claude Code and Codex for video editing tasks yet. However, Claude has long been established as a foolproof option for almost any task.

To use Claude Code, you need a Claude Pro or Max subscription or an API key with pay-as-you-go usage, meaning for tokens actually spent. You can get an API key payable in rubles from SpeShu.AI: Claude Opus 5.5 and Claude Sonnet 5 models are available there without a foreign card, and the documentation describes an Anthropic-compatible API address for agent tools.

How Claude Edits Video It Doesn't See

The main concern of skeptics: how can a text-based neural network edit video? The answer is simple: it doesn't edit the video, but its transcript.

Imagine you're given a printout of an interview where each word has a timestamp indicating when it was spoken. You cross out "uh," repetitions, and awkward phrases with a pen, and an assistant cuts the recording based on your marks. You haven't watched the video yourself, but in essence, you've edited it. Claude does exactly the same:

  1. The recording is transcribed into text. Each word has an exact timestamp, pauses and laughter are marked, and who is speaking is visible.

  2. Claude reads this text and decides what to keep and what to cut.

  3. If it's unclear what's happening at a certain point, for example, a long pause or two similar takes, Claude looks at a few frames from that segment.

  4. It records its decisions as a list of cuts: "take from 0:12 to 0:47, then from 1:03 to 1:30."

  5. The free program FFmpeg assembles the video based on this list.

  6. Claude checks the finished video at the cuts and, if something is wrong, re-edits it. Up to three attempts.

From this, we get the main conclusion that explains all the strengths and weaknesses of auto-editing. Everything related to speech, Claude edits well: speech is converted to text, and the neural network works best with text. Everything related to visuals, it edits poorly: it only sees the visuals as individual frames.

For those who want to dive deeper. All takes are packed into a single text file, takes_packed.md, about 12 KB in size — a few thousand tokens instead of gigabytes of video. For ambiguous parts, the skill creates a timeline_view: a PNG with a storyboard, an audio waveform, and word labels. Decisions are recorded in an EDL (edit decision list), rendering is done via FFmpeg, project state is stored in project.md, so editing can be continued in the next session. This is the same idea browser-use used to build browser control: the agent is given not a page screenshot, but its structured text description. Only instead of DOM, it's a transcript with timestamps.

What Auto-editing Can Do

Cleans Up Conversational Video

  • removes filler words, stutters, and long pauses;

  • cuts between words, not in the middle of a sound;

  • if you repeat a phrase several times, it keeps the best take;

  • smooths the audio at each cut to avoid clicks.

Styles the Video

  • performs color correction: warm "cinematic," neutral, or as per your description;

  • adds subtitles, the style of which is set by text;

  • inserts an intro and an outro card.

Creates Animations

Claude doesn't draw animation inserts but programs them: it writes code that a special program uses to assemble the animation. There are three tools for this:

  • Remotion — for product videos, interfaces, charts;

  • Manim — for formulas, diagrams, and scientific explanations;

  • HyperFrames by HeyGen — for animated graphics described as a web page.

B-roll — inserts with other footage — is not created by video-use itself; it needs to be placed in the folder beforehand. Such inserts can be generated by video models, for example, in Studio with ready-made presets.

For those who want to dive deeper. At each cut, a 30ms audio fade is applied, subtitles by default show two words per line in uppercase, color correction is set by a preset or a custom FFmpeg filter chain. Animations are assembled in parallel by sub-agents. Remotion describes video as React components, HyperFrames as HTML and CSS rendered via headless Chrome, Manim as Python scenes.

Weaknesses of Auto-editing

Cannot See the Visuals

The command "put this shot after he smiled" requires understanding the image. Claude only sees the transcript and individual frames, so editing based on emotions, movement, or visual appeal is not its forte.

Makes Mistakes Based on Transcription Errors

If the transcription software mishears a word or a pause, the error will carry over into the edit. In noisy recordings, with strong accents, or in Russian, there might be more such errors.

Requires a Detailed Script for Complex Projects

Two cameras, multiple speakers, B-roll — all of this works, but only if you meticulously describe what should be where. Without a description, Claude will focus on the speech.

Does Not Replace an Audio Engineer

It has limited noise reduction capabilities and cannot mix music and effects at a professional level.

Becomes More Expensive with Recording Length

Transcription is charged per minute of recording, and Claude uses more tokens for longer text. A one-hour project is significantly more expensive than a ten-minute one, and with a Pro subscription, you can easily hit the limit on such a project.

Requires Technical Skills

Editing skills are not needed, but you will have to install programs via the terminal, i.e., the command line. For those who have never opened a terminal, the first launch will take time.

What Goes Online and What Stays on Your Computer

The video itself is not sent anywhere: cuts and video assembly are performed by FFmpeg on your computer. What goes online:

  • the audio track — to a cloud transcription service, if you use one instead of local transcription;

  • the transcript and your instructions — to the Claude model;

  • a few frames from ambiguous segments — also to Claude.

If the recording is confidential, such as an internal call or an NDA-protected interview, transcription can be done directly on your computer. More on this below.

Step-by-Step Guide: How to Get Started

Installation

Enter the commands in the terminal one by one:

# 1. Install Claude Code

npm install -g @anthropic-ai/claude-code

# 2. Install FFmpeg (command for Mac; on Linux — via package manager)

brew install ffmpeg

# 3. Download video-use and connect it to Claude Code

git clone https://github.com/browser-use/video-use ~/Developer/video-use

ln -sfn ~/Developer/video-use ~/.claude/skills/video-use

# 4. Install skill dependencies

cd ~/Developer/video-use

uv sync            # or: pip install -e .

# 5. Transcription service key — in the .env file according to the README instructions

After that, it's all in plain language: open Claude Code in the folder with your recordings and describe what needs to be done. Claude will understand that the task is about editing and will activate the skill.

How to Edit for Free: freecut

freecut is a free version of video-use where paid cloud transcription is replaced by the Whisper program, which runs directly on your computer. No keys are needed, and recordings never leave your computer. The downside: the project is young, with about 250 stars compared to 30,000 for the original, and updates reach it with a delay.

For those who want to dive deeper. freecut is a fork of video-use under the same MIT license with pluggable transcription backends. By default, it uses mlx-whisper on Apple Silicon and faster-whisper on other systems. A GPU with CUDA is only needed for optional speaker diarization via VibeVoice-ASR.

Ready-Made Prompts for Auto-editing

It's best to write prompts in English: the skill and its instructions are in English, and Claude follows instructions more accurately in the same language.

Cleaning video for YouTube:

Edit the interview in this folder. Remove filler words, false starts and pauses longer than 0.7 seconds. When a phrase is repeated, keep the last complete take. Add burned-in subtitles, two words per line, white with a black outline. Export 1080p.

Short vertical video for social media:

Cut a 45-second vertical 9:16 clip from this recording. Keep only the part where I explain the pricing. Start with the strongest sentence, add large centered subtitles and a 1-second title card with the text "Pricing explained". Warm color grade.

Lecture with formula animation:

Edit this lecture recording into a 6-minute video. Remove pauses and repeated sentences. At 02:10, where I explain the formula, insert a Manim animation that builds the equation step by step. Keep my voice over the animation.

Product demo from screenshots:

Create a 30-second product demo using Remotion. Use the screenshots in /assets in this order, animate a cursor clicking through the signup flow, add short captions for each step and the logo at the end. Export 1080p MP4.

A good prompt answers five questions:

  1. Which files to use and in what order.

  2. What is the desired result: duration, vertical or horizontal format, quality.

  3. What to cut: which pauses, which takes to keep.

  4. How to style: subtitles, color, intro.

  5. What inserts and at what moments.

How to Check the Finished Video

Claude checks technical cuts itself, but you check the meaning:

  • cuts don't chop words in half;

  • subtitles match the speech, names and terms are spelled correctly;

  • volume doesn't jump between segments;

  • pauses that were part of the delivery haven't been cut;

  • animations appear at the right moment and don't obscure important content.

If something is wrong, don't look for the spot yourself: write a correction with the timestamp, and Claude will reassemble the video.

Common Mistakes

Describing the Task in a Single Phrase

"Edit it beautifully" will yield an average result. Specify the duration, format, what to keep, what to cut, and how to style subtitles.

Recording in Noise

Noise interferes with transcription, and transcription errors become editing errors. Record audio with a separate microphone or clean up the recording beforehand.

Expecting Visual Editing

Claude edits based on speech. If a gesture, smile, or shot change is important, specify the exact time yourself.

Not Reviewing the Result

Claude checks cuts, but not the meaning. Watch the entire video before publishing.

Editing a Multi-Hour Project on a Pro Subscription

Long recordings quickly consume the limit. Divide them into parts or switch to pay-as-you-go.

Forgetting Remotion's License

For teams larger than three people, it's paid. This needs to be considered in advance for commercial content.

Buying an Annual Subscription Through an Intermediary

If access rules change, you could lose money for the remaining months. Monthly payments or token-based payments are safer.

Frequently Asked Questions

How does auto-editing in Claude work?

The recording is transcribed into text, where each word has a timestamp. Claude reads this text, decides what to cut, and creates a list of cuts, which the free program FFmpeg uses to assemble the video. Claude only looks at frames in ambiguous situations.

Can I edit videos in Claude for free?

Not entirely: Claude Code requires a Claude Pro subscription starting at $20 per month or a pay-as-you-go API key. The rest can be free: FFmpeg, on-computer transcription via freecut, and animations in Manim and HyperFrames.

Do I need editing skills?

No: the task is described in plain language. However, you'll need to install several programs via the terminal once.

What videos does Claude edit best?

Those where speech is primary: interviews, podcasts, lectures, videos where a person speaks to the camera. Worst are videos where editing depends on visuals: emotions, movement, shot composition.

Can auto-editing be used for commercial purposes?

video-use itself is distributed under the MIT license, which permits commercial use. Limitations may apply to individual tools: Remotion is free only for individuals and teams of up to three people; cloud transcription terms depend on the plan. Copyright for the original recordings and music remains with you.

Conclusion

Auto-editing in Claude is not a scam, but it's not a magic button either. Claude doesn't watch the video; it edits its transcript, so it excels at conversational videos and is almost useless where decisions depend on visuals. It doesn't become better than specialized AI video tools — it solves a different task, and it does it quickly. If you regularly produce interviews, podcasts, lectures, or demo videos, this saves you hours every week. If you edit only occasionally, your usual editor is still faster.
