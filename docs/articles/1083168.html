A lot of pelicans on bicycles have started appearing in my Twitter feed, so I decided to conduct my own, somewhat chaotic, experiment.

Goal: To cover everyday models that can be easily tested for generation quality and get a comparative assessment of the models' capabilities.

Prompts

They are listed below, but since the task of generating a pelican has existed for at least a couple of years, I decided to modify the prompt a bit to ensure the model isn't just reproducing a memorized solution but is actually thinking something up on the topic.

Original Prompt - Pelican on a Bicycle

The following text was formulated:

Write a one-page HTML with SVG animation: a cartoon pelican (white/light yellow, with a large gular pouch) riding a bicycle with radial spokes, wheels spinning, legs pedaling, background shifting backward to simulate motion, purely on CSS Keyframes, no external libraries

Second Prompt - Frog on an Old-Fashioned Bicycle

Write a one-page HTML with SVG animation: a cartoon frog (green/light yellow, with large eyes) riding a penny-farthing bicycle with radial spokes, wheels spinning, legs pedaling, background shifting backward to simulate motion, purely on CSS Keyframes, no external libraries

Third Prompt - Pelican on a Bicycle in the Era of Skynet's Victory

Write a one-page HTML with SVG animation: a cartoon pelican (white/light yellow, with a large gular pouch) riding a bicycle with radial spokes, wheels spinning, legs pedaling, background shifting backward to simulate motion, purely on CSS Keyframes, no external libraries. Post-apocalyptic style and Skynet war.

Models

The following models were tested:

The Essence of the Experiment

Each prompt is sent to a separate chat with a clean session and the connected model. No hints or additional input are provided (there is an exception, but more on that below). If the chat supports a reasoning on/off mode, generations are performed in both modes, and the best result is chosen. At the end of the model's work, the HTML file result is checked for (these are still subjective criteria):

  • overall visual design quality: style, aesthetics, stylistic consistency

  • correct implementation of the bicycle: wheels, rotation of wheels and pedals, frame, handlebars, proportions

  • design of the background and road, its detail

Exceptional Situations

Several exceptional situations arose during the work, which were decided to be disregarded as they should not significantly affect the result:

  1. DeepSeek has a limitation on outputting reasoning, and a "Continue" button appears. The button was pressed, and the reasoning continued from the same point.

  2. GigaChat has some issues with outputting raw HTML code in code blocks: it breaks into parts, with some code in the chat area and some in the block area. I had to copy the text and remove the garbage lines from the "Copy" code blocks.

  3. Alice quickly generated the file pelican.html and provided a broken link to it. I had to ask her to output the page text in the chat every time.

Conclusions

By Points

  1. Frontier models (GPT Astra) outperform other models. Russian models (Alice AI, GigaChat) lag significantly behind – at the level of previous generations (about 10-12 months, it seems). DeepSeek shows results comparable to recent top models (the model was updated just the other day, the result might already be better).

  2. Locally deployed Qwen 3.8 (27B) show excellent results. And this is with sizes about 370 times smaller (27 billion parameters versus 10 trillion for GPT Astra). Such models can be confidently used with high quality of the resulting output.

  3. Qwen 3.8 Flash (125B) — a new architecture, the results are promising, but currently slightly inferior to the regular Qwen 3.8 in some nuances. Higher generation speed, slightly less prone to lengthy reasoning (statistics are not yet collected, but a decrease of about 10-15%).

  4. Multimodality is a key factor. The model's ability to look at the generated result (screenshot → iteration) will radically improve the outcome. Even Qwen 3.6 will achieve normal pedal rotation in a few iterations, but the better the first result, the easier it is to bring it to completion.

  5. Reasoning mode works differently. For Qwen 3.8 — it provides deep analysis (but generation takes from 1 hour 40 minutes to 2 hours 40 minutes). For Alice AI — it worsens the result: the model decides to "simplify everything and finish later," leading to catastrophic simplifications. DeepSeek shows stable results in reasoning mode.

  6. Agent cycle on modest hardware. Qwen 3.8 — for verification/planning/review, Qwen 3.6 — as an executor. In an agent cycle with multiple iterations, similar results can be achieved on relatively modest hardware.

Interesting Observations

  1. Nibiru or Planet X is present in most pelican-Skynet generations.

  2. The drones are surprisingly similar across models, as is the entire Skynet generation setting.

  3. I expected to see more signs of distillation in the Qwen models, but they are not particularly noticeable.

  4. The entire Twitter feed is filled with Chinese pelican generations, and people are also moving towards creating unique prompts to test model generations. They've reached the pelican on a bicycle, which is on the wing of a plane controlled by a bear.

  5. I caught myself thinking: what are we burning tokens on? Some 10,000 agents are solving the problem of the millennium, while others are drawing pelicans.

  6. The increase in model generation quality is clearly non-linear. And now, it's even symbolic. The gap in the number of parameters is colossal. Small models that can be run on accessible hardware are catching up. I have high hopes for promising new architectures.
