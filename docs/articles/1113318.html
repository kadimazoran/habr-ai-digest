In the beta version of Telegram for macOS, Dictator has appeared — an AI agent that can work with correspondence, create documents, write code, and perform tasks on the user's computer. Early users are already testing the application and publishing reviews of its capabilities.

Within Telegram itself, the agent can search for information in correspondence, find unanswered messages, and prepare drafts. The agent can be controlled from a smartphone via its own Telegram bot.

Three permission levels are provided for different actions: Allow, Ask, and Never. For example, a user can allow the agent to read messages, require it to ask for confirmation before sending, and prohibit message deletion. Secret chats and authorization codes are not accessible to the agent.

Telegram does not tie Dictator to a specific language model. You can connect a ChatGPT subscription, use the API from OpenAI, Anthropic, xAI, or OpenRouter, or run a local LLM. When using a cloud model, requests are sent to the chosen provider.

The agent runs in a separate virtual machine with Linux. The user can access the terminal and execute commands independently. According to TestingCatalog, Dictator is presumably based on Hermes Agent from Nous Research. The agent's capabilities can be extended with plugins, including those for Claude Code, Xcode, Notion, and Linear.

In addition to agent functions, Dictator includes system-level voice input. Simply hold down the Option key in any application and dictate text — the AI will correct grammatical errors and insert the result at the cursor's position.

On November 26, a practical review of Dictator appeared on YouTube. To work, the agent currently requires a Mac with an Apple Silicon processor and macOS 14 or newer. Telegram has not yet announced a stable release date or plans to support other operating systems.
