1.2. Why Inspect Models Before Training

Before building a student, we need to answer two questions:

  1. Which model to use as a base? cointegrated/rubert-tiny2 and sergeyzh/rubert-tiny-turbo — both have 3 layers, 312 dim, 29.4M parameters (turbo is tiny2 fine-tuned on contrastive; the architecture is the same).

  2. How to aggregate tokens into a single sentence? The teacher uses mean pooling (from the model card), but we have our own attention head. We need to understand which layer provides the most "semantic" signal.

Metric for comparison — gap. Defined as:

gap = mean(cos of similar pairs) - mean(cos of dissimilar pairs)

In the "dissimilar" part of the formula, hard and easy negatives are mixed; they are shown separately below to see the contribution of each type.

The larger the gap, the better the model distinguishes semantics, and the "cleaner" its space. An ideal model would have a large gap (similar — close, different — far).

Test set — 10 pairs, specially selected:

  • 4 positive (paraphrases): "cat on a chair" - "cat sat down", "died of a heart attack" - "life was cut short by a heart attack".

  • 3 hard negatives (negations): "he got a job" - "he did NOT get a job", "I love cats" - "I do NOT love", "appointed" - "canceled".

  • 3 regular negatives (different topics): "cat" - "airplane", "borscht" - "Pythagoras".

Iterating through combinations:

  • Layers: embeddings, L0, L1, L2 (all model outputs).

  • Pooling strategies: mean, cls, max, last-token.

This is a reconnaissance set, not a quality assessment. These 10 pairs are needed to select the layer and pooling strategy. Quality conclusions are made separately — on hnp_val (590 pairs) and an external set (5000 pairs) in the following sections.

Goal: find the combination with the maximum gap. It's also important to look at cos of hard negatives.

"""Layer and pooling strategy reconnaissance.

Comparing:
- cointegrated/rubert-tiny2 (base LM, 3 layers, 312 dim)
- sergeyzh/rubert-tiny-turbo (sentence encoder, 312 dim)
- DeepPavlov/rubert-base-cased-sentence (teacher, 12 layers, 768 dim)

Pooling: mean / CLS / max / last-token
"""
import sys
from pathlib import Path

import numpy as np
import torch
import torch.nn.functional as F
from transformers import AutoModel, AutoTokenizer

DEVICE = torch.device("cpu")

torch.manual_seed(42); np.random.seed(42)

MODELS = [
    ("cointegrated/rubert-tiny2", "base LM"),
    ("sergeyzh/rubert-tiny-turbo", "sentence enc"),
    ("DeepPavlov/rubert-base-cased-sentence", "teacher"),
]

PAIRS = [
    ("кошка сидит на стуле", "кот уселся на стуле", 1),
    ("он умер от инфаркта", "его жизнь оборвал сердечный приступ", 1),
    ("психология травмы и стадии горя", "этапы переживания утраты", 1),
    ("студент сдал экзамен на отлично", "учащийся успешно прошёл испытание", 1),
    ("он устроился на работу", "он не устроился на работу", 0),   # hard
    ("я люблю кошек", "я не люблю кошек", 0),                      # hard
    ("врач назначил лечение", "врач отменил лечение", 0),          # hard
    ("кошка сидит на стуле", "самолёт летит в небе", 0), # тот же anchor, теперь с негативом
    ("повар готовит борщ", "теорема Пифагора", 0),
    ("история Древнего Рима", "строение ДНК", 0),
]

HARD_NEG_INDICES = [4, 5, 6]  # indices of hard negatives in PAIRS (0-based)


def mean_pool(h, m):
    mm = m.unsqueeze(-1).float()
    return (h * mm).sum(1) / mm.sum(1).clamp(min=1e-9)

def cls_pool(h, m):
    return h[:, 0]

def max_pool(h, m):
    mm = m.unsqueeze(-1).float()
    h = h.masked_fill(mm == 0, float("-inf"))
    return h.max(1).values

def last_pool(h, m):
    # index of the last real token
    lengths = (m.sum(1) - 1).clamp(min=0)  # [B]
    return h[torch.arange(h.size(0)), lengths]

POOLERS = {
    "mean": mean_pool,
    "cls": cls_pool,
    "max": max_pool,
    "last": last_pool,
}


def l2(x):
    return F.normalize(x, dim=-1)


def evaluate_model(model_id, tag):
    print(f"\n{'='*80}")
    print(f"Model: {model_id}  ({tag})")
    print(f"{'='*80}", flush=True)

    model = AutoModel.from_pretrained(model_id).to(DEVICE).eval()
    tokenizer = AutoTokenizer.from_pretrained(model_id)

    cfg = model.config
    print(f"  layers={cfg.num_hidden_layers}  hidden={cfg.hidden_size}  " 
          f"heads={cfg.num_attention_heads}  vocab={cfg.vocab_size}  " 
          f"max_pos={cfg.max_position_embeddings}")
    n_params = sum(p.numel() for p in model.parameters())
    print(f"  params={n_params:,}  ({n_params*4/1e6:.1f} MB fp32)")

    texts = [a for a, _, _ in PAIRS] + [b for _, b, _ in PAIRS]
    labels = [lbl for _, _, lbl in PAIRS]
    n = len(PAIRS)

    enc = tokenizer(texts, padding=True, truncation=True, max_length=256,
                    return_tensors="pt")

    with torch.no_grad():
        out = model(**enc, output_hidden_states=True)

    hidden_states = out.hidden_states  # tuple (n_layers+1)

    print(f"\n  {'layer':<12} {'pool':<6} {'sim+':>7} {'sim-':>7} {'gap':>7} {'hard-':>7}")
    print(f"  {'-'*50}")

    best = (None, -999)
    for layer_idx, hidden in enumerate(hidden_states):
        for pool_name, pool_fn in POOLERS.items():
            emb = l2(pool_fn(hidden, enc["attention_mask"]))
            pos_s, neg_s, hard_s = [], [], []
            for i, (a, b, lbl) in enumerate(PAIRS):
                s = float((emb[i] * emb[n + i]).sum())
                if i in HARD_NEG_INDICES:
                    hard_s.append(s)
                if lbl == 1:
                    pos_s.append(s)
                else:
                    neg_s.append(s)
            p, nn, hh = np.mean(pos_s), np.mean(neg_s), np.mean(hard_s)
            gap = p - nn
            layer_name = f"emb" if layer_idx == 0 else f"L{layer_idx-1}"
            print(f"  {layer_name:<12} {pool_name:<6} {p:>7.3f} {nn:>7.3f} " 
                  f"{gap:>7.3f} {hh:>7.3f}")
            if gap > best[1]:
                best = ((layer_name, pool_name, emb), gap)

    # Analysis of the best
    (layer_name, pool_name, emb), gap = best
    print(f"\n  Best combination: layer={layer_name}  pool={pool_name}  gap={gap:.3f}")
    print(f"  Pair analysis:")
    for i, (a, b, lbl) in enumerate(PAIRS):
        s = float((emb[i] * emb[n + i]).sum())
        tag = "POS" if lbl == 1 else ("HRD" if i in HARD_NEG_INDICES else "NEG")
        print(f"    [{tag}] {s:+.3f}  {a[:40]:<42} <-> {b[:40]}")

    return best


def main():
    print(f"Device: {DEVICE}")
    results = {}
    for model_id, tag in MODELS:
        try:
            best, gap = evaluate_model(model_id, tag)
            results[model_id] = (best[0], best[1], gap)
        except Exception as e:
            print(f"\n[!] {model_id} failed: {e}")
            results[model_id] = None

    print(f"\n{'='*80}")
    print("SUMMARY")
    print(f"{'='*80}")
    for model_id, r in results.items():
        if r is None:
            print(f"  {model_id:<50} FAILED")
        else:
            layer, pool, gap = r
            print(f"  {model_id:<50} best={layer}/{pool}  gap={gap:.3f}")


if __name__ == "__main__":
    main()

Three conclusions:

  1. Turbo is almost 2x stronger than tiny2. Both models have the same architecture (3 layers, 312 dim), but turbo is fine-tuned contrastively on Russian data (see model card). This gave it a ready understanding of semantics, whereas tiny2 remains a base MLM model; its representations are not optimized for text comparison.

  2. The teacher is 2.5x stronger than turbo. DeepPavlov with 12 layers and 768 dim has a much richer representation. Our task is not to match its absolute semantics, but to get close enough for retrieval and deduplication to work.

  3. The teacher suffers from negation blindness (see 1.5).
