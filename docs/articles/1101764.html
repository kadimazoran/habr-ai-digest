What's on HuggingFace: The Tabs

The main tabs on HuggingFace are Models, Datasets, and Spaces.

Models (huggingface.co/models) is a repository of weights. This is where you'll find the files downloaded and run locally or via transformers: Llama, Qwen, Stable Diffusion, Whisper, and millions of other checkpoints. A model in this section is a collection of tensors and configuration, not a ready-to-use application. To make it work, you need code, a GPU, or at least a Python pipeline.

Datasets (huggingface.co/datasets) is a storage for training and evaluation data. It contains text corpora, images, audio, and tables that can be loaded with a single line: load_dataset("name"). We won't be covering this tab in this article, as it's intended for those who plan to fine-tune or build their own benchmarks, rather than run pre-trained weights.

Spaces (huggingface.co/spaces) are live demos. Each Space is a small web application built with Gradio, Streamlit, or Docker, running on HuggingFace's infrastructure and accessible directly in your browser without installation. The model is already loaded, weights are downloaded, and a GPU is allocated. You input text or an image, get the result, and close the tab.

We'll primarily focus on the Models section, as that's where you choose what to download and what hardware resources to allocate. Spaces are useful for trying out a model before committing to downloading gigabytes of data.

How to Read a Model Card Without Downloading Junk

Let's examine a model card using a specific example: zai-org/GLM-5.3, one of the top open-source models, released in August 2026.

At the top, you'll see tags: Text Generation, Transformers, Safetensors, English, Chinese, glm_moe_dsa, conversational. The first tag is the Task the model is trained for. Text Generation means the model produces text: answers questions, completes code, or engages in dialogue. If you need summarization or classification, you'll look for different tags, which will determine which class from the transformers library you'll load. Safetensors is a weight storage format that replaced pytorch_model.bin and is considered more secure and faster to load. glm_moe_dsa is an architectural tag, which we'll discuss later.

For GLM-5.3, the License: glm-5.3 tag links to a separate document, indicating a custom license from Z.ai. This license permits commercial use with certain conditions (specifically, a revenue threshold of ten billion dollars, after which the terms change).

Model popularity is also crucial. At the time of writing, this model had Downloads last month: 2,507,023. Two and a half million downloads in a month is a rough but effective indicator that the model is not broken and that there are discussions available. If a model has only five hundred downloads and its issues section is silent, you're likely to be the first to encounter a bug. However, popularity doesn't tell you if the model is suitable for your specific task.

Model size is also important. In the screenshot within the Safetensors block, you can see the line Model size 753B params. This is the total number of parameters in the model. However, this model uses the MoE (Mixture of Experts) architecture, where only a portion of the weights are activated at each generation step – around 40 billion parameters. This is why a 753-billion-parameter model can sometimes run faster than a dense model of comparable size. Nevertheless, for local execution, this still means you'll need a server with substantial memory, not just a laptop.
