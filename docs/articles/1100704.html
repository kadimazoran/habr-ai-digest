Lumio is a free app for the MacBook notch. It shows what your AI agents are currently doing: who is working, who has finished, who is waiting for command permission. You can grant permission directly from the notch, without switching to the terminal. There's also a pixel office where each session is a person at their desk.

Until today, Lumio understood Claude Code, Codex, Cursor, GitHub Copilot, and Antigravity. In version 1.3, OpenCode, Kilo Code, and Pi were added. It might seem like just three more lines in the settings. In reality, it's three different ways to connect and a week of work, two days of which were spent not on code, but on testing it with real agents without paid keys.

Each agent has its own language

Here's how Lumio learns about events from different agents:

Agent

How Lumio knows what's happening

Claude Code

hooks in ~/.claude/settings.json, our script writes a line to the log

Codex

the only notify slot is already taken by many, so we read session files ~/.codex/sessions/…/rollout-*.jsonl

Cursor

hooks + a small Lumio extension, through which the reply to the permission request comes

GitHub Copilot

its own hooks file ~/.copilot/hooks/lumio.json

Antigravity

its hooks, our script writes a line to the log

OpenCode, Kilo

JS plugin in ~/.config/opencode/plugins/ and ~/.config/kilo/plugins/

Pi

extension in ~/.pi/agent/extensions/

Inside Lumio, all this is reduced to one format — Claude Code hook events: SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, Stop. We chose it not out of love for Anthropic, but because it was the first and cards, the office, and daily summaries are already written for it. Each new agent is a translator into this format, not a new branch in the interface.
