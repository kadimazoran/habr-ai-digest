What is OpenResearch

OpenResearch is a local workspace for research agents. You install the CLI orx, run orx up, and a dashboard opens at http://127.0.0.1:4791. There, you assign a task to a coding agent: find literature, formulate a hypothesis, write code, run an experiment, and analyze the results.

Project capabilities:

  • Parallel research. Each direction has its own agent session and its own isolated git worktree. Multiple agents can simultaneously try different ideas.

  • Reproducible experiments. Variants are stored in a Git-native experiment tree, and each run receives an immutable archive of the recorded commit.

  • Evidence in context. Logs, diffs, files, results, and artifacts are tied to the work that generated them.

  • Agent selection and model for each session. After our additions, there are eight agents: Claude Code, Codex, OpenCode, Cursor, Google Antigravity, Kimi Code, MiniMax Code, and ZCode.

  • Computation selection. You can compute locally, via SSH, on Slurm, Kubernetes, Ray, Hugging Face Jobs, Modal, Tinker, or on managed computations at openresearch.sh.

  • Literature. The commands orx discover, orx paper, and orx lit search alphaXiv, OpenAlex, bioRxiv, and PubMed.

  • Everything locally. Projects, chats, experiments, runs, logs, code, and artifacts reside in SQLite and files on your machine. Creating a project or running a task does not publish anything.

  • Auto-research. An agent can independently go through a cycle: propose an idea, modify code, run an experiment, observe the results, and decide what to try next.

Under the hood, orx is a Rust program. The dashboard is written in React and embedded in the binary. Each agent is connected via its own adapter (harness): the adapter knows how to find the agent's CLI, validate input, execute a turn, and parse the event stream.
