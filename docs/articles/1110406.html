Developer Benj Edwards has presented a local ChatGPT for SNES model project for the 16-bit Super Nintendo Entertainment System console, released in 1990. The project is based on a small language model with approximately 2.2 million parameters, running on the Super FX 2 coprocessor of a flash cartridge. ChatGPT for SNES has no relation to OpenAI.

Edwards offers ROM files for the basic and extended versions of ChatGPT for SNES. The first weighs 4 MB and independently generates all words in its responses. The second version, weighing 19 MB, additionally uses a knowledge base based on Simple English Wikipedia, containing opening sentences from 150,000 Wikipedia articles. The model can access this base, find the necessary information, and present it to the user.

The ChatGPT for SNES code was written by artificial intelligence agents. Dialogues for training the model were created using the OpenAI model with open weights — gpt-oss-120b.

The author admits that ChatGPT for SNES is a useless assistant. The model is millions of times smaller than those that form the basis of ChatGPT. It knows only 8,000 words and often makes mistakes, sometimes confidently, Edwards notes. According to him, the knowledge base of the extended build may also contain errors. ChatGPT for SNES can be run in a browser via an emulator.

Previously, developer WollyMonjac presented an open-source project of a small language model on Turbo C 2.0, which runs under DOS on an old Pentium or 486DX and fits on a single floppy disk.
