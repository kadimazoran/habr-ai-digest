Hello, Habr. My name is Mikhail Burlakov. This article is about a project that started with a question, not a technology. What happens to an agent that doesn't solve one task but *lives* — for a long time, in a world that is constantly changing? What will it remember, and what will it forget? How will memory, mood, and habit compete within it? And can we, by observing its actions, understand why it acted that way?

The default modern answer is: take a large model, define a loss function, and train with gradients. This works brilliantly for text recognition and generation. But I had a different subject — a creature that learns sequentially, one episode at a time. In this mode, global gradients are prone to catastrophic forgetting: new updates overwrite old ones. I wanted to build an agent differently, using the mechanisms by which animals cope with this problem. By day, they record experience quickly and "roughly," and rewrite long-term memory at night, during sleep. This resulted in NOWA-Cognitive — a cognitive architecture without backpropagation, without a global loss function, and without a language model in the decision loop.

The code is on GitHub: github.com/burlakovmb/NOWA-Bio-Inspired-AI. It's about 125,000 lines of Python, including tests and demos. The core itself in src/ uses only the standard library. Explaining the structure as a list of modules would be boring, so I'll walk you through one day of a specific agent's life and explain each mechanism when it becomes relevant.

Meet G3A1SF

Our protagonist is named G3A1SF. She didn't choose her name; it was assigned by the colony generator according to the pattern G{generation}A{number}S{sex}: third generation, first in that generation, female. She was born in a short run of the colony with generator seed 11, which I'll discuss later. Her parents are G2A1SF and G2A2SM, and her lineage traces back to six of the eight founders.

In the screenshot, she is very young: five seconds of model time, five steps. This is convenient for the explanation — almost everything that will shape her personality, she has yet to experience. I'll be upfront: the "daytime" episodes below are illustrative. I'm describing what the core modules would do with such events. The events themselves are generated by the colony (Demo/Colony chinchillas/src/colony_agent.py): found food, an alarm signal from a frightened neighbor, a stranger nearby. This is not a log of her real life. However, the formulas and constants are taken directly from the code, with file paths included.

Morning: How She Sees the World and Makes Choices

The world comes to G3A1SF not as an image, but as a set of contextual tokens like context:forage and event:found_hay. The hippocampus (src/hippocampus.py) responds first. It searches memory for similar episodes and activates them. A young individual has very few such episodes. This is intentional: short-term memory here is a draft, written immediately and without much ceremony.

Simultaneously, her mood shifts. In NOWA, emotion is not a set of flags like "scared / happy," but a single continuous vector of eight axes ranging from -1 to 1: valence, arousal, dominance, stress, trust, curiosity, stability, and attachment (AXES in src/affective_space.py). Each step, the vector gradually returns to its baseline and receives impulses from three sources — the external world, memories, and internal states:

A(t+1) = baseline + decay · (A(t) − baseline) + external + from_memory + internal − λ · (A(t) − baseline)

In simple terms: mood is inertial but not infinite. Each axis has its own decay rate. Stress decays faster by default (0.75), dominance lasts longer (0.97), and these coefficients, as we'll see later, are inherited. One detail I consider important: the impulse from memory is limited to 30% of the average external impulse. A memory can color the present, but it cannot drown it out.

Now she needs to do something. Each possible action is a channel in the basal ganglia (src/basal_ganglia.py), and the channels compete using a "Go vs. NoGo" scheme:

Go   = pressure · (1 + 0.9 · dopamine) + 0.6 · habitNoGo = |pressure| · (1.2 · cortisol + 0.8 · unpleasantness)result = max(Go − NoGo − threshold, 0)

The pressure on a channel is collected by the selector (Agent._extract_selector_pressures) from activated hippocampus episodes, cortical patterns, intention memory, temporal chains, and the prediction layer. Dopamine enhances the resolve to act, cortisol and the sense of threat inhibit it, and habit adds inertia. Affect also enters here, through a linear decision matrix: for example, risk-taking increases with valence and dominance and decreases with stress (DEFAULT_DECISION_MATRIX). This is how G3A1SF develops caution and reaction speed, which fine-tune NoGo and Go. The final choice is made by a "thalamic" softmax, and its temperature increases with norepinephrine: T = T0 · (1 + 0.6 · NE) · …. An anxious and aroused animal chooses more randomly — it explores.

Note that none of the five neuromodulators *decide* anything here. The docstring for NeuromodulatorState states it directly: "Neuromodulators modulate, they do NOT make decisions." They change scales and thresholds, while the choice remains with the channel competition. This principle runs through the entire architecture.

Surprise: Prediction Error Instead of Gradients

Suppose G3A1SF goes for hay and finds it — reward +0.85. What does she learn from this? This is where the main divergence from conventional machine learning occurs. There is no global loss function across all parameters. There is a local value — how much the outcome was better or worse than expected. The value layer (src/value_layer.py) stores a tabular state value V(s) and calculates the classic TD error:

δ = r + γ · V(s') − V(s),   γ = 0.95

If δ is positive, the world was more generous than expected; if negative, it was worse. This same δ becomes a phasic dopamine surge: clamp(0.5 · δ, −0.1, 0.1). Neuroscientists will recognize this — dopamine as a reward prediction error. Now imagine a conspecific in high stress nearby. If their stress is above 0.7, they emit an alarm signal: in the colony, this is the event alarm_call. The signal itself pushes the listener's stress up — by 0.3 if the neighbor is known, and by 0.15 if not (_perceive_alarm_calls). If, in such a state, the outcome turns out worse than expected, an asymmetry I intentionally built-in kicks in: in stress, a negative error is amplified, δ · (1 + 0.35 · stress). A frightened animal remembers bad things more strongly than good. Cortisol and norepinephrine also increase. Norepinephrine reacts to novelty and conflict, with conflict first passing through the anterior cingulate cortex model: high norepinephrine and cortisol amplify it, serotonin dampens it (_compute_effective_conflict_from_state).

Here I must correct the nice formula "learns by day, only learns by night" — even my own quick-start script prints this. During the day, V(s) still receives a small online update: V ← V + α · δ with α = 0.03 and a soft ceiling of 0.15. The magnitude of this update is regulated by acetylcholine — a modulator of attention and novelty:

ach_effective = max(0.0, ach_v - ach_baseline_v)alpha_v = alpha_v * (1.0 + (ach_gain * ach_effective))   # ach_gain = 0.4

The more unusual the situation, the more plastic the evaluation. Conversely, if an expectation is already confident and stable, the update decreases — α · (1 − confidence · stability · 0.8). However, a real "prediction shock" increases the update. More importantly: during the day, the weights of action channels, habits, and long-term memory patterns are not touched. The update_weights method for channels is only called from the sleep loop. During the day, G3A1SF only accumulates material — episodes with recorded prediction error, acetylcholine level, and "shock" — so that there is something to process at night.

Night: What Remains, What Fades

When sleep pressure builds up (the "process S plus circadian process C" model is described in the preprint; G3A1SF's rhythm amplitude and chronotype are set by genes), the agent falls asleep. Sleep in NOWA is not background retraining, but a separate call to SleepManager.sleep_cycle() in src/sleep.py. This is where most of the project's meaning resides.

First, sleep checks if memory can be rewritten at all. If the value estimates are too scattered (variance above 0.25), replay is blocked entirely. An unstable agent should not solidify its instability. Then, each daytime episode goes through a filter. Too small a prediction error (|δ| < 0.12), too noisy, an insufficiently salient event, lack of reinforcement or attention — and the episode does not enter consolidation. The reasons for rejection are counted separately, so after each night, it's clear *why* something wasn't remembered. An episode with found hay and an unsuccessful episode against an alarm signal will likely pass: both were unexpected. A routine minute at the feeder — no.

From those that pass, sleep selects what to "replay" again. The priority is formulated simply:

priority = |δ| · (1 + shock) · (1 − stability)

This should be read in words. What needs repeating is what was surprising and what hasn't settled yet; what is already understood doesn't need repeating. On top of this, priority is boosted by acetylcholine, recorded during the episode. The selection is probabilistic, with a budget of 32 replays per night and a limit on repeating the same thing. Then, the replays are ordered by time, and each episode is assigned a "causal depth" — how far it was from the reward moment, within a window of six steps. Value updates during sleep decay with this depth (λ^depth with λ = 0.85 and exp(−depth/3)). If G3A1SF first went for hay, then found it, and then ate it, the entire chain receives credit, but the steps closest to the reward get more.

And only now do the action channels change. A channel that led to a good outcome gets an increase in Go and a decrease in NoGo proportional to δ: go += 0.015 · 1.15 · δ, nogo −= 0.015 · 0.85 · δ. For a bad outcome, it's mirrored. After this, weights are necessarily decayed and normalized. Phase 5.A.2 specification directly requires that repeated reinforcements do not lead weights to saturation. Similar episodes (similarity at least 0.8) merge into a cortical pattern — thus, the hippocampus draft becomes long-term knowledge. Temporal chains are formed from recent episodes. Finally, everything unstable, rarely reinforced, and inactive is forgotten: episodes with stability from 0.2, with three or more reinforcements, or with high activation remain in memory.

Neuromodulators work more subtly at night than during the day. Dopamine slightly strengthens cortical patterns (strength · (1 + 0.05 · DA)). Serotonin increases the stability of recent episodes. High cortisol raises the forgetting threshold (0.2 + 0.2 · CORT), and after a hard day, the agent forgets weaker traces more. High norepinephrine triggers an additional pass for forming longer chains. Night itself is classified as slow-wave sleep, REM, or transitional phase — based on average arousal, "shock," and confidence in the selected episodes. The coefficients of semantic consolidation depend on the phase. Regarding the code, honestly: NeuromodulatorState has generalized "handles" like get_learning_rate_modifier() and get_forgetting_rate(), but the sleep cycle core uses the direct rules described above, and these getters are currently only called by the Tamagotchi demo.

If you run the quick start, the day and night results are visible in the output: after five episodes and one sleep cycle, the agent from sixty_seconds.py had its dopamine rise from 0.10 to 0.50, norepinephrine to 0.52, acetylcholine to 0.25, and its affect shifted (valence +0.49, stress +0.15). In the morning, it's already a slightly different creature.

Inheritance: What G3A1SF Received from Her Parents and What She'll Pass On

Why does G3A1SF's stress decay the way it does, and why does she recover from sleep slower than her neighbors? Part of the answer is written in her genome. GenomeVector in src/genome.py consists of 39 genes, each defining a coefficient for some module: the strength of mutual inhibition between dopamine and norepinephrine, the half-life of neuromodulator decay, the inertia of each mood axis, the amplitude and phase of the circadian rhythm, thresholds for curiosity and sociability, the speed of online learning, the consolidation threshold, the lifespan multiplier. Each gene has bounds, a default value, and its own mutation σ:

("nm_da_ne_weight", "neuromodulators", -0.4, 0.0, -0.2, 0.05, "DA to NE inhibition"),

In the colony, a descendant receives exactly the average of their parents' genes (arithmetic crossover with alpha = 0.5), and then each gene is shifted with a 5% probability by Gaussian mutation. This means that everything distinguishing G3A1SF from the "average of her parents" is the result of mutations. The "Gene Changes" tab shows this directly: recovery -0.182 ("recovers slower after sleep"), sensitivity to cortisol -0.124 ("stress affects the body less"), sociability threshold +0.100.

The genome only changes parameters, not the connection scheme between modules. I chose this limitation consciously, even though it narrows what evolution can provide. There is also a second channel of inheritance — the epigenome (src/epigenome.py). This is a limited snapshot of what the parent has *already consolidated* during sleep: up to 32 patterns, 16 actions, and 24 value profiles. By default, traces with at least two reinforcements are included. When passed on, noise is added to the strength of each trace, and if the descendant already has a pattern for the same context, the stronger one wins. The Same Mind in a Different Body

For me, the most interesting aspect of the colony is not the chinchillas themselves, but the separation of mind and body. The core knows nothing about cages, hay, or wheels. It receives context tokens and returns an action channel choice. From here, the next step is to place the same mind in a completely different body.

The most practical of these bodies is an agent interacting with an external MCP server (src/mcp_body/). Tools become organs: reading acts as sensory input, writing as muscles. The mind chooses *which* tool to use, and the body gathers arguments from the tool's schema, the world state, and weights derived from the same 8-dimensional affect (caution, cost aversion, novelty seeking). A language model is not needed at any step. Since the muscles here can, for example, pay bills, the safety loop is strict. Each new tool is assigned a risk class by name: get_/list_ are read-only, create_/send_ are medium write, pay_/transfer_ are high, delete_/revoke_ are irreversible. Ambiguous names fall into a higher risk class, and the administrator must confirm the class before issuing the tool. Any write operation to the external world goes through an ApprovalGate. Reading is performed immediately, while anything requiring approval goes into a queue and waits for a human to accept, correct, or reject. The decision is returned to the agent as a standard reward: +1.0 for accepted, +0.4 for corrected, -1.0 for rejected, -0.2 for expired. Thus, a human approver teaches the agent with the same dopamine signal that hay teaches a chinchilla.

The disassembled example involves procurement in Demo/Virtual company/: a sandbox with suppliers and demand, a host for "employees," and a role configurator. A role is defined by data. Money, permissions, and limits reside in the body, outside the cognitive loop. Sleep occurs on schedule, at night. Two more bodies are simpler. Tamagotchi is a single instance with continuous visualization, useful for observing how need, affect, and habit change. The Warriner norm comparison is a benchmark, not a home: the colony receives words as stimuli, and its average valence shift is compared to human ratings by Warriner, Kuperman, and Brysbaert (2013). I'm deliberately not providing correlation numbers here: the result comes from running the validator, and checking rank agreement verifies affective mapping, not understanding of word meaning.

What G3A1SF Cannot Do Yet

If you've read this far, you probably have one question: how does this compare to standard RL? The honest answer is: I don't know. There's no direct comparison with PPO or SAC on the same task in the repository. Currently, verification relies on behavioral plausibility and regression tests, so there are no benchmarks in the article. In the preprint (Docs/arxiv_NOWA_ru.md, section 6.2), I list other weaknesses, which directly follow from the above discussion. Reward, novelty, and conflict in the colony are defined heuristically. Evolution tunes parameters but doesn't invent new connections. The agent's "imagination" recombines memory and is not a trained model of the world. The epigenome is a compressed snapshot, not culture. The MCP body has been tested with invariants in the lab, but no one has yet placed it alongside a live operator on a real task.

There's also engineering honesty of a different kind. Coefficients like weights in consolidation evaluation or multipliers of 1.15 and 0.85 in channel updates are taken from phase specifications. These are hand-made decisions, not values fitted to data. Docs/ contains many lab reports on development phases. They are preserved as a log, and the current contract is defined by normative specifications and code. If you find a place where the document and code diverge, trust the code and please write to me. I am, after all, a natural intelligence and might forget to update the documentation when editing code ;).
