Introduction

In today's world, machine learning models are used in many areas, such as medicine, finance, transportation, and cybersecurity. In fact, there are many more such areas.
But what is a machine learning model? Is it an algorithm trained on data, a "black box," or something else? Today we will figure this out.

First - terms.

In this post, I have used some terms that require understanding. Below is a brief description of everything you need to know to read the post.

Approximation (mathematics) — replacing something complex (a function, a number) with something simpler, but still similar enough to the original.
For example, the number e is often replaced by 2.718, which is an approximation.

Determinism (mathematics) — this is when the same input always gives the same output.
For example, the function kx+b is deterministic, as it takes a specific x and produces a specific result, fixed for that x.

Stochasticity — a property of a process where the outcome cannot be precisely predicted. Instead of a deterministic result, we get a probability distribution.
For example, rolling a die: we don't know exactly what we'll get. But we know that the probability of rolling each number is one-sixth.

Semantics (linguistics) — this is the science that studies the meanings of words, signs, phrases, and everything related to it.
For example, the word "key" can be interpreted differently, depending on the rest of the context.

Extrapolation (mathematics) — this is an attempt to predict the value of a function for an argument that is outside the known range, using the function's behavior within the known range.
For example, analyzing the behavior of the function x^2 in the range [-2;2] and predicting its possible value at point 3.

A model is not magic!

As we all know, a model is a mathematical function that adjusts its weights to minimize a loss function, which, in turn, depends on the data. That is, the model "learns" the data structure and tries to give correct answers based on this data. For convenience, let's call the data some function f(x), and the model a function g(x) that tries to approximate f(x).

Based on this, it can be argued that a model is a kind of function approximator. But most importantly, it depends on f(x) itself and the domain of x. If, for example, f(x)=cos⁡(x), and in our data x takes all values from the range [−2;2], then the model has the ability to replicate this function well within this range. However, outside of this range, the result will likely be incorrect (assuming the function behaves differently in the unknown segment. But still, the error will accumulate if the function is non-linear). This can be considered a kind of "hallucination": the model gave an answer, but it has nothing to do with reality.
