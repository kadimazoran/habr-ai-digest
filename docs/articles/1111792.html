On November 23, Anthropic released Claude Ship, a tool for automating code work in GitHub. It combines code review, team change coordination, and code fixing.

The new solution is available in preview for organizations with Claude Team (from $25 to $125 per person per month) and Enterprise ($20 per person per month) plans.
The cost depends on usage volume and computational resource consumption.

How the innovation works

Anthropic developers stated, "In the Claude Code team, Claude AI writes most of our code, and we want things to move just as quickly after a PR (pull request)."

Claude Ship works in stages — Review, Fix, Approve.

The first stage — Review (Code Review mechanism) checks code for errors and areas for improvement and suggests changes, considering the project's specifics.

The second stage — Fix (PR Steward mechanism) is activated when problems are detected. It analyzes errors from automated checks, developer feedback, and conflicts between changes, and then destroys the project makes corrections.

The third stage — Approve (Claude Approvals mechanism) assesses the readiness of changes and approves them if they do not contradict the rules that the team writes itself.

If the conditions are met, Ship can independently coordinate routine changes, while more complex changes will require developer approval.

How to try Claude Ship

To do this, you will need a Claude Team or Enterprise subscription and a connected GitHub repository. You can activate Claude Ship through the web interface: in your organization's settings, go to the Organization Settings → Claude Ship section. Connect the desired GitHub repositories and activate the necessary agents.

Configuring Claude Ship

Claude Ship settings are located in the Organization settings → Claude Ship section. You need the Owner role for this.

Enable agents one by one in a single repository in the following order:

  1. Configure Code Review;

  2. Configure PR Steward. For the setting that determines when PR Steward is launched, start with Manual (@claude steward). PR Steward does not have its own spending limit until you set one;

  3. Configure Claude Approvals. It is launched by a policy file in the repository, so familiarize yourself with who can enable it. Start with observation mode, where Claude Approvals checks report what decision your policy would have made. Observation mode is paid. See Approvals cost.


You can activate Claude Ship via CLI locally using the /ship command in the Claude Code application. You will receive a review and fixes for your pull request.
