Google introduced Gemini 3.8 Live with Live Avatar. The model accepts voice, image, video, and text, and responds through an animated character with lip-sync, facial expressions, and voice.

This is not a separate talking-head generator attached to a chatbot. The avatar is built directly into the conversational model and can see the interlocutor, listen to them, respond, and access external services during the conversation.

What Live Avatar Can Do

Gemini generates video with an avatar at a resolution of up to 24 frames per second. Lip movements are synchronized with speech, and facial expressions change with the intonation of the response.

The model supports switching between 97 languages directly during a conversation. Lip-sync and facial expressions should adapt to the new speech without restarting the session.

Gemini 3.8 Live also includes two more features by default.

  • Affective dialogue helps the model consider the interlocutor's speech tempo, pauses, intonation, and emotional cues. Simply put, the agent should distinguish a calm question from an irritated complaint and change its response style accordingly.

  • Proactive audio filters out background noise and extraneous conversations. The model tries to respond only when addressed directly. Useful for an office, store, or hotel where there is ambient life.

The Agent Can Work During a Conversation

One of the most interesting capabilities is related to asynchronous tool calls.

Function calling allows the model to access external functions and services. For example, checking a reservation, finding an order in CRM, or requesting data from an internal system.

Previously, a voice agent often had to interrupt the conversation and wait for a server response. Gemini 3.8 Live can continue the dialogue while the required operation is performed in the background.

In Google's demonstration, a virtual employee registers a guest at a hotel. The avatar talks to the person and simultaneously accesses the booking system. The user no longer has to wait with a "Your request is being processed" message.

What's Under the Hood

According to Google Cloud documentation, interaction occurs via a bidirectional WebSocket connection. This allows for continuous data transfer between the application and the model without creating a new request for each utterance.

The model accepts audio in PCM format at 16 kHz, text, and video frames in JPEG format. Incoming video is analyzed at a rate of up to one frame per second. The agent outputs audio at 24 kHz, text, and MP4 video with an avatar at 24 frames per second.

The context window is up to 128 thousand tokens. When using Live Avatar, the model can output up to 24 thousand tokens. The context window determines how much information the system can consider within a single session.

Google offers ready-made characters and a set of voices. Companies will also be allowed to create their own avatars from a single reference image. The model preserves the character's appearance and turns a static image into a talking digital employee.

However, custom avatars are currently only available to select clients after approval from Google Cloud. The use of images of minors and celebrities is prohibited. The company also requires obtaining the necessary rights to the face and voice.

Where the Model is Available

Live Avatar is launched in Gemini Enterprise. Gemini 3.8 Live itself has General Availability status in Google's enterprise platform, meaning it is no longer an experimental preview.

Use cases are quite obvious. Virtual consultants, support staff, educators, game characters, digital guides, and administrators gain a visual presence without a separate animation engine.

The cost of Live Avatar is not disclosed in Google's announcement.

How Google Suggests Distinguishing an Avatar from a Human

Audio and video created by the model receive invisible SynthID watermarking. This is a Google DeepMind technology that embeds a machine-readable watermark directly into the generated content.

This watermark does not interfere with viewing but allows verification of the recording's origin. At least, if the platform actually performs such verification.

This is especially important for talking avatars. The more natural the digital character looks and reacts, the easier it is to use it not only for customer support but also for outright deception.

Limitations Have Not Disappeared

In the model card, Google states that Live Avatar is designed for only a few minutes of continuous interaction, not for multi-hour sessions.

Delays, timeouts, and hallucinations are also possible. The model's knowledge cutoff date is January 2025. To obtain current information, the agent will require an external data source.

Therefore, Live Avatar cannot yet be considered a digital employee that can be placed at the reception desk in the morning and picked up in the evening. It is an interface for short conversational scenarios within which the agent performs a limited set of actions.

What's the Bottom Line

Google has combined a conversational model, video generation, visual context recognition, and tool calling into a single API. Developers no longer need to separately connect a language model, speech synthesis, and a facial animation engine.

This can significantly simplify the creation of visual AI agents. Especially for support, training, and services where a human face increases engagement.

However, a face does not make the model smarter or more reliable. Now AI can make mistakes while looking the user directly in the eyes. Progress should still be felt.
