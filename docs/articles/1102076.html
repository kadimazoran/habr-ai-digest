Let's explore Convolutional Neural Networks (CNNs), which are an adaptation of the neural network structure to specific data characteristics.

What is a Convolutional Neural Network?

Convolutional Neural Networks were created for pattern recognition. The main task of this architecture was to create a network where the initial layer extracts local features, and subsequent layers combine them into higher-level features.

When using this approach, the fundamental task of pattern recognition is reduced to feature detection functions, i.e., functions capable of determining the presence or absence of local visual elements in an image. Moreover, it should understand that the element exists regardless of its location.

To achieve this spatial independence in feature detection, neurons in CNNs use shared weights.

In the context of pattern recognition, the function implemented by a neuron can be considered a visual feature detection mechanism.

For example, neurons in the first hidden layer of the network receive a set of pixel values as input. If a specific pattern (local visual element) is present, they activate strongly.

The fact that the function implemented by a neuron is determined by its weights means that two neurons with the same set of weights implement the same function (feature detection mechanism).

If two neurons have different input data (receptive fields), they collectively behave like a feature detection mechanism for their common dataset, activating if the feature is present in at least one set.

Basic Operations for CNNs

The figure above illustrates different processing stages often found in CNNs.

The 6x6 matrix on the left represents the input image. To its right is a 4x4 matrix representing a layer of neurons that collectively scan the image for a specific local feature. Each neuron is connected to a 3x3 receptive field of the image, and all apply the same 3x3 weight matrix to their input.

Here, the receptive fields overlap because they have a stride of one. The stride is a hyperparameter chosen by the user.

Essentially, a convolution operation is performed: we sequentially apply the same weight matrix (convolution matrix or kernel) to different parts of the input data. The result of the scalar multiplication of the matrices is a number, which is written into one of the cells of the feature map.

It should be noted that the convolution operation does not include a non-linear activation function; that will be applied later.

After the feature map is filled, a non-linear activation function is applied to its elements.

Pooling Operation

After the convolutional layer has found features (e.g., edges, corners, textures), we proceed to pooling.

What does pooling do?

  • Reduces the dimensionality of the feature map.

  • Makes the network more robust to small shifts and distortions in the image.

  • Extracts the most important features from each region.

Essentially, we divide our feature map into smaller squares (this is called a pooling window). For each square, we take the maximum value (Max Pooling) or the average value (Average Pooling) and write it into a new, reduced map.

Typically, convolution, applying a non-linear activation function, and pooling are referred to as a convolutional layer. There can be many such layers, but ultimately, we obtain a dense or fully connected layer.

All neurons in the dense layer receive input from all neurons in the previous layer, and it is the dense layer that generates the final output.
